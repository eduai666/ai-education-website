# 第四章图片说明

本目录存放 `docs/markdown/04-什么是智能体/` 各课使用的 PNG 信息图。

第四单元正在拆分为多个三级课程文件。现有图片先作为候选素材保留；待六课文字定稿后，再统一确认每张图对应的课文位置、是否需要重做，以及是否还要补充新图。本阶段不新增图片。

## 文件

### `01-agent-system.png`

- 内容：用户目标、模型、控制程序和工具之间的关系，以及工具结果怎样回到模型。
- 解释任务：说明模型提出下一步，控制程序检查并执行工具，工具结果再成为新的信息。
- 替代文字：用户目标进入智能体后，模型提出工具请求，控制程序检查并执行工具，再把结果交回模型。

### `02-agent-loop.png`

- 内容：从目标与限制出发，依次观察、选择、行动和检查；未完成时继续，完成或需要人工确认时退出循环。
- 解释任务：说明智能体怎样根据中间结果继续推进任务，并在高风险或缺少权限时请人确认。
- 替代文字：智能体从目标出发，反复观察、选择、调用工具并检查结果，在完成、超限或高风险动作前停止。
