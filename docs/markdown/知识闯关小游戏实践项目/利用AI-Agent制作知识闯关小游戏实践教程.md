# 实践项目：利用 AI Agent 制作知识闯关小游戏

## 一、项目介绍

在这个项目中，你将通过与 AI Agent 对话，制作一个可以在浏览器中运行的知识闯关小游戏。

游戏会依次显示若干道选择题。玩家选择答案后，程序会判断回答是否正确，并在全部题目完成后显示最终得分。

你不需要从头编写所有代码，但需要完成下面这些工作：

1. 确定游戏主题和功能；
2. 向 Agent 准确描述需求；
3. 运行并测试 Agent 生成的程序；
4. 找出程序中的问题；
5. 通过多轮对话不断完善作品；
6. 检查题目和答案是否准确。

在这个过程中，Agent 是帮助你开发程序的助手，而你才是项目的设计者、测试者和最终负责人。

---

## 二、最终作品效果

完成后的小游戏至少应具备以下功能：

- 显示游戏名称和玩法介绍；
- 每次显示一道选择题；
- 每道题包含四个选项；
- 玩家点击选项后判断正误；
- 回答后显示正确答案和简单解释；
- 点击按钮进入下一道题；
- 完成所有题目后显示最终得分；
- 提供“重新挑战”按钮。

你还可以继续增加：

- 倒计时；
- 连续答对奖励；
- 错题回顾；
- 随机打乱题目；
- 最高分记录；
- 不同难度；
- 音效和动画；
- 手机端适配。

完成项目后，你应当能够：

1. 把一个模糊的想法拆分成具体功能；
2. 使用自然语言向 Agent 描述程序需求；
3. 理解网页中 HTML、CSS 和 JavaScript 的大致作用；
4. 根据实际运行结果判断程序是否正确；
5. 准确描述程序出现的问题；
6. 通过多轮对话让 Agent 修改程序；
7. 核验 AI 生成的题目和答案；
8. 说明哪些内容由自己决定，哪些内容由 Agent 完成。

# 第一阶段：设计你的游戏

## 五、确定游戏主题

首先选择一个你感兴趣的主题，例如：

- 古诗词知识闯关；
- 英语单词挑战；
- 中国地理知识问答；
- 历史年代闯关；
- 物理现象判断；
- 化学元素知识挑战；
- 生物细胞知识问答；
- 网络安全知识闯关；
- 人工智能基础知识挑战。

本教程以“人工智能基础知识闯关”为例。你也可以把主题替换成自己正在学习的学科内容。

## 六、填写项目设计表

在与 Agent 对话之前，先完成下面的设计。

| 设计问题 | 我的决定 |
|---|---|
| 游戏名称是什么？ |  |
| 游戏面向谁？ |  |
| 一共有多少道题？ |  |
| 每道题包含哪些内容？ |  |
| 什么情况下算完成游戏？ |  |
| 页面采用什么颜色和风格？ |  |

第一次制作时，建议只使用 5 道题。每道题包含题目、四个选项、正确答案和答案解释。不要一开始制作几十道题，因为题目越多，检查和修改的工作量越大。

# 第二阶段：让 Agent 创建最小版本

## 七、为什么要先制作最小版本

很多同学第一次使用 Agent 时，会提出这样的要求：

> 帮我制作一个非常好玩、功能丰富、画面精美的知识闯关游戏。

这个要求看起来很完整，但实际上过于模糊。Agent 可能会一次加入大量功能，导致页面结构复杂、程序难以修改，出现问题后也不知道错误在哪里。

更合理的方法是先制作一个功能简单但可以运行的版本，这叫作“最小可行版本”。第一版只需要：

- 5 道题；
- 每题 4 个选项；
- 判断正误；
- 记录得分；
- 显示最终成绩；
- 支持重新开始。

## 八、向 Agent 发送第一轮提示词

将下面的提示词发送给支持编程的 Agent：

```text
我要制作一个可以在浏览器中运行的“AI知识大挑战”小游戏，使用 HTML、CSS 和 JavaScript 实现。

第一版只实现以下功能：

1. 游戏一共有5道单选题；
2. 每道题有4个选项；
3. 玩家点击选项后，显示“回答正确”或“回答错误”；
4. 回答后显示正确答案和一句简短解释；
5. 点击“下一题”进入下一道题；
6. 完成全部题目后显示得分；
7. 提供“重新挑战”按钮；
8. 页面采用简洁的蓝色科技风格；
9. 页面需要适合电脑和手机浏览；
10. 暂时不要加入登录、联网、排行榜和服务器功能。

请把程序制作成一个可以直接打开运行的 HTML 文件。代码中加入适量中文注释，方便初中生理解。
```

## 九、不要立刻要求增加功能

Agent 生成程序后，先不要马上加入倒计时、动画或排行榜。你应该先确认最基本的功能是否正常。如果最小版本存在错误，继续增加功能只会让问题更复杂。

# 第三阶段：运行并测试程序

## 十、第一次运行

如果 Agent 生成了一个 HTML 文件，可以按照下面的方法运行：

1. 找到生成的 HTML 文件；
2. 使用浏览器打开；
3. 查看游戏页面是否正常显示；
4. 从第一题开始完成一次完整挑战；
5. 分别测试答对和答错的情况。

如果使用的是带预览功能的 Agent 开发工具，也可以直接点击“运行”或“预览”。

## 十一、基础测试清单

请逐项检查，并记录结果。

| 测试项目 | 是否通过 | 发现的问题 |
|---|---|---|
| 页面可以正常打开 |  |  |
| 游戏标题显示正确 |  |  |
| 第一题正常出现 |  |  |
| 每道题有四个选项 |  |  |
| 点击选项后能判断正误 |  |  |
| 正确答案显示正确 |  |  |
| 答案解释能够显示 |  |  |
| 点击下一题能继续 |  |  |
| 完成五道题后显示得分 |  |  |
| 重新挑战后分数归零 |  |  |
| 手机大小窗口中内容完整 |  |  |

测试时不要只选择正确答案。你至少需要测试以下三种情况：

1. 所有题目都答对；
2. 所有题目都答错；
3. 一部分答对，一部分答错。

## 十二、检查计分是否正确

假设游戏一共有 5 道题，每道题 20 分。请测试：

- 答对 5 题，应显示 100 分；
- 答对 4 题，应显示 80 分；
- 答对 3 题，应显示 60 分；
- 全部答错，应显示 0 分。

如果显示结果不符合预期，就说明计分逻辑可能存在问题。

# 第四阶段：学习准确描述问题

## 十三、不要只说“程序有问题”

当程序出现错误时，下面这种反馈对 Agent 帮助不大：

> 游戏坏了，帮我修一下。

更有效的描述应该包括：

- 你进行了什么操作；
- 你原本期待看到什么；
- 实际发生了什么；
- 问题是否每次都会出现。

例如：

```text
我完成5道题后，最终页面显示答对4题，但是分数显示为60分。按照每题20分计算，应该显示80分。请检查计分逻辑，只修改与得分计算有关的部分，并说明错误产生的原因。
```

## 十四、常见问题及对话示例

### 问题一：可以连续点击多个选项

可能出现的现象：玩家回答一道题后，仍然可以继续点击其他选项，导致分数重复增加。

```text
当前玩家回答一道题后，仍然可以点击其他选项，而且点击正确答案后分数可能重复增加。请修改程序，使玩家每道题只能作答一次。作答后禁用所有选项，直到点击“下一题”。
```

### 问题二：重新开始后分数没有清零

```text
点击“重新挑战”后，题目从第一题重新开始了，但是上一次的得分还保留着。请在重新开始时同时重置当前题号、得分和作答状态。
```

### 问题三：没有回答也能点击下一题

```text
现在玩家没有选择任何答案，也可以直接点击“下一题”。请让“下一题”按钮在玩家完成当前题目后才显示，或者在未作答时保持不可点击。
```

### 问题四：手机上选项显示不完整

```text
当浏览器窗口宽度较小时，选项按钮中的文字超出了页面。请优化 CSS，使页面在手机屏幕上能够正常显示，按钮宽度适应屏幕，长文字可以自动换行。
```

### 问题五：答案解释显示时间太短

```text
玩家回答后，解释内容很快消失，没有足够时间阅读。请不要自动进入下一题，让玩家阅读解释后主动点击“下一题”。
```

# 第五阶段：核验题目和答案

## 十五、Agent 生成的题目不一定正确

Agent 可以帮助你生成题目，但它可能出现：

- 题目表达不清；
- 正确答案设置错误；
- 多个选项都可能正确；
- 解释与答案不一致；
- 内容过于困难；
- 使用了不准确或过时的信息。

因此，所有题目都必须经过人工检查。不能因为题目是 AI 生成的，就默认它一定正确。

## 十六、建立题目核验表

| 题号 | 题目是否清楚 | 答案是否正确 | 解释是否准确 | 是否需要修改 |
|---|---|---|---|---|
| 1 |  |  |  |  |
| 2 |  |  |  |  |
| 3 |  |  |  |  |
| 4 |  |  |  |  |
| 5 |  |  |  |  |

核验题目时，可以参考：

- 学校教材；
- 教师提供的资料；
- 权威科普网站；
- 可靠的工具书；
- 多个相互独立的资料来源。

## 十七、让 Agent 协助检查题目

你可以把题目发给 Agent，请它协助检查：

```text
请检查下面5道人工智能基础知识题。重点检查题目是否存在歧义、正确答案是否唯一、解释是否准确，以及内容是否适合初中生。请先指出问题，不要直接修改程序。
```

但是，即使 Agent 表示“全部正确”，你仍然需要查看教材或可靠资料。让同一个 Agent 检查自己生成的题目，并不能完全消除错误。

# 第六阶段：理解程序的基本结构

## 十八、让 Agent 解释代码

你不需要马上看懂所有代码，但至少应该知道程序包含哪些部分。可以向 Agent 提问：

```text
请不要修改代码，用适合初中生的语言说明这个小游戏由哪几个主要部分组成。重点说明 HTML、CSS 和 JavaScript 分别负责什么，以及题目、得分和当前题号分别存在哪里。
```

### HTML 负责网页结构

例如游戏标题、题目区域、选项按钮、得分区域、下一题按钮和重新开始按钮。HTML 可以理解为网页的“骨架”。

### CSS 负责页面外观

例如页面颜色、字体大小、按钮样式、页面间距、手机屏幕适配，以及答对和答错时的颜色。CSS 可以理解为网页的“服装和装修”。

### JavaScript 负责程序逻辑

例如显示当前题目、判断答案、更新得分、切换下一题、显示最终成绩和重新开始游戏。JavaScript 可以理解为网页的“大脑和控制系统”。

## 十九、寻找保存题目的位置

请让 Agent 指出题目在代码中的位置：

```text
请指出程序中保存题目的代码，并解释每道题中的 question、options、answer 和 explanation 分别表示什么。不要修改程序。
```

题目数据可能类似下面的结构：

```javascript
{
  question: "人工智能系统主要依靠什么进行学习？",
  options: ["数据", "运气", "声音大小", "屏幕颜色"],
  answer: 0,
  explanation: "很多人工智能模型需要从大量数据中发现规律。"
}
```

其中：

- `question` 表示题目；
- `options` 表示选项；
- `answer` 表示正确答案的位置；
- `explanation` 表示答案解释。

注意：有些程序从 0 开始计算选项位置。如果 `answer: 0`，通常表示第一个选项正确，而不是“没有正确答案”。

# 第七阶段：自己修改项目内容

## 二十、替换题目

接下来，不要让 Agent 决定全部题目。请你自己准备至少两道题，并要求 Agent 替换。

```text
请保留现有程序功能和页面样式不变，把第4题和第5题替换为我提供的题目。

第4题：大语言模型生成回答时，是否一定完全正确？

选项：
A. 一定正确
B. 不一定，需要核验
C. 只要回答很长就正确
D. 只要语气肯定就正确

正确答案：B

解释：大语言模型可能生成事实错误或不准确的信息，因此重要内容需要核验。

第5题：下面哪一种做法更适合使用AI完成学习任务？

选项：
A. 直接复制AI答案
B. 不阅读就提交
C. 检查答案并用自己的语言表达
D. 让AI代替自己参加考试

正确答案：C

解释：AI可以提供帮助，但学生仍需要理解、判断和独立表达。
```

修改后，你需要再次测试这两道题。

# 第八阶段：进行第一次功能升级

## 二十一、加入错题回顾

完成基础版本后，可以增加一个真正有学习价值的功能：错题回顾。

```text
请在现有游戏基础上增加“错题回顾”功能。

具体要求：

1. 记录玩家答错的题目；
2. 游戏结束后显示错题；
3. 每道错题显示玩家选择的答案、正确答案和解释；
4. 如果玩家全部答对，显示“本次没有错题”；
5. 不要修改现有题目内容；
6. 修改后说明你新增了哪些变量和函数。
```

## 二十二、测试错题回顾

### 情况一：全部答对

预期结果：显示满分，并显示“本次没有错题”。

### 情况二：答错一道题

预期结果：只显示这一道错题，玩家答案和正确答案显示无误，答案解释能够阅读。

### 情况三：全部答错

预期结果：显示全部错题，不遗漏任何一道，页面内容仍然能够正常浏览。

# 第九阶段：进行第二次功能升级

## 二十三、加入随机题序

每次游戏都按照相同顺序出题，时间长了以后，玩家可能只记住题目顺序。可以让 Agent 增加随机功能：

```text
请在每次开始游戏和点击“重新挑战”时随机打乱题目顺序。

要求：

1. 不要修改题目本身；
2. 同一道题在一轮游戏中不能重复出现；
3. 重新挑战时应重新随机；
4. 请说明随机打乱发生在程序的哪个阶段。
```

测试时连续重新开始三次，观察题目顺序是否发生变化。

# 第十阶段：设计自己的个性化功能

## 二十四、选择一个创意升级

从下面选择一项即可，不建议一次全部加入。

| 方案 | 功能说明 |
|---|---|
| 倒计时 | 每道题限制 15 秒，超时自动判错 |
| 连续答对奖励 | 连续答对 3 题时额外奖励 10 分 |
| 难度选择 | 游戏开始前可以选择简单或困难模式 |
| 最高分记录 | 使用浏览器本地存储保存最高分 |
| 主题切换 | 允许玩家选择科技蓝、森林绿或星空紫主题 |
| 声音控制 | 答对、答错和结束时播放不同音效，并提供静音按钮 |

## 二十五、编写自己的升级提示词

不要只说“帮我增加倒计时”，而要把功能和异常情况说明清楚。例如：

```text
请在现有知识闯关游戏中增加每题15秒倒计时。

具体要求：

1. 每道题开始时从15秒倒数；
2. 玩家完成作答后停止计时；
3. 时间归零时自动判定本题错误；
4. 超时后显示正确答案和解释；
5. 进入下一题后重新从15秒开始；
6. 点击重新挑战后清除旧计时器；
7. 避免多个计时器同时运行；
8. 不要修改题目内容和原有计分规则。
```

# 第十一阶段：完成最终测试

## 二十六、最终测试清单

### 功能测试

- [ ] 每道题只能回答一次；
- [ ] 分数计算正确；
- [ ] 下一题切换正常；
- [ ] 最后一题结束后进入结果页面；
- [ ] 重新开始后所有状态重置；
- [ ] 错题回顾内容正确；
- [ ] 随机题序没有重复；
- [ ] 新增功能正常运行。

### 内容测试

- [ ] 题目没有错别字；
- [ ] 四个选项表达清楚；
- [ ] 正确答案唯一；
- [ ] 答案解释准确；
- [ ] 内容适合初中生；
- [ ] 没有未经核验的事实。

### 界面测试

- [ ] 标题清晰；
- [ ] 文字大小合适；
- [ ] 按钮容易点击；
- [ ] 答对与答错提示明显；
- [ ] 页面没有内容重叠；
- [ ] 手机屏幕下可以正常显示。

### 异常测试

## 二十八、项目介绍示例

> 我制作的是一个面向初中生的 AI 基础知识闯关小游戏。游戏包含 5 道选择题，玩家回答后可以看到正确答案和解释。
>
> 第一版程序存在重复点击选项后分数重复增加的问题。我通过测试发现这个错误，并要求 Agent 在玩家作答后禁用全部选项。

>
> 在这个项目中，Agent 帮助我生成和修改代码，但游戏主题、功能要求、题目内容和测试方法主要由我决定。

# 三十一、使用 Agent 时必须遵守的规则

1. 不在提示词中填写真实姓名、电话、家庭住址、学校班级等个人信息；
2. 不把账号密码或 API 密钥发送给 Agent；
3. 不直接复制来历不明的代码到重要设备中运行；
4. 不制作收集他人隐私信息的程序；
5. 不使用 Agent 生成攻击、作弊或破坏性程序；
6. 不把 Agent 生成的内容直接当作正确答案；
7. 重要事实必须经过可靠资料核验；
8. 提交作品时应说明 Agent 参与了哪些部分；
9. 自己必须运行、测试并理解最终作品；
10. 发现异常时及时停止运行并向老师求助。

# 项目总结

在这个项目中，真正重要的并不是你是否独立写出了每一行代码，而是你是否完成了一个真实的开发过程：

> 明确目标 → 拆分功能 → 描述需求 → Agent 生成 → 运行测试 → 发现问题 → 准确反馈 → 修改完善 → 核验内容 → 展示反思

使用 Agent 开发程序，不等于把任务全部交给 AI。

优秀的项目开发者需要知道自己想做什么，能够判断 Agent 生成的结果是否正确，也能够通过测试和对话把不完善的作品一步步变成可以使用的产品。
