# 图片与图表说明

本目录保存“机器学习与深度学习”章节的配图。正文使用相对路径引用这些文件。

| 文件 | 类型 | 用途与来源说明 |
| --- | --- | --- |
| `machine-learning-hero.png` | PNG 主视觉 | 使用 OpenAI 内置图像生成能力制作的原创教学插图，无品牌与可识别文字 |
| `learning-pipeline.svg` | SVG 教学图 | 本项目原创绘制；概念参考 Google Machine Learning Crash Course |
| `learning-types.svg` | SVG 教学图 | 本项目原创绘制；说明监督、无监督与强化学习的反馈差异 |
| `neural-network.svg` | SVG 教学图 | 本项目原创绘制；说明神经元、多层网络与信息流 |
| `training-loop.svg` | SVG 教学图 | 本项目原创绘制；说明前向传播、损失、反向传播和参数更新 |
| `generalization.svg` | SVG 教学图 | 本项目原创绘制；概念参考 Google 关于过拟合与泛化的课程 |
| `architecture-map.svg` | SVG 教学图 | 本项目原创绘制；比较 MLP、CNN、RNN/LSTM、ResNet 与 Transformer |

生成主视觉时使用的最终提示词摘要：面向 10—14 岁读者，用暖色现代学习空间表现“多样数据卡片 → 多层神经网络 → 预测结果”的流程；采用精致 3D 编辑插画与信息图结合的风格，不含文字、品牌、水印、机器人或大脑图标。
