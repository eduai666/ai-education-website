# 深度与表示学习：模型怎样逐层“看见”复杂特征

## 本课目标

- 解释深度学习中的“深”指什么；
- 理解特征工程与表示学习的差异；
- 知道端到端学习减少了哪些人工步骤，又保留了哪些人的责任。

## “深”首先是计算结构，不是思想深刻

深度学习中的“深”，主要指神经网络包含多层信息变换。它不表示模型具有深刻思想，也不表示层数越多就必然越聪明。

先想象一场校园科技节比赛。任务是让计算机判断照片里有没有猫，两支队伍选择了不同路线。

**规则队**先采访宠物医生，再把经验变成可以测量的项目：有没有尖耳朵、胡须附近有没有细线、轮廓是否像四足动物、毛发纹理是否明显。队员把这些特征提取出来，再交给一个分类模型。普通家猫的照片上，这套方法效果不错；可是遇到无毛猫、只露出尾巴的猫、戴着猫耳发箍的人，规则队就需要继续修改特征。

**深度学习队**没有先规定“必须寻找胡须”。他们收集了许多带有“猫/不是猫”标签的图片，让多层神经网络直接从像素中学习哪些组合有助于降低分类错误。训练早期，网络也许只能区分亮暗和边缘；随着参数更新，它逐渐形成纹理、轮廓、局部部件以及更抽象的组合表示。

比赛结果不会永远是深度学习队获胜。如果只有几百条整齐的表格记录，规则队使用决策树可能更快、更省电，也更容易说明理由；如果有大量复杂图片，而且猫的姿态、背景和光线变化很多，深度学习队往往更有优势。真正专业的选择不是“追最新模型”，而是先看任务和数据。

多层网络可以把一个复杂映射拆成许多相对简单的步骤：

> 原始输入 → 简单局部模式 → 组合结构 → 更抽象表示 → 任务输出

例如图像网络在训练中可能形成：

> 像素变化 → 边缘与方向 → 纹理和轮廓 → 局部部件 → 完整对象

这是一种帮助理解的概括。真实网络中的特征分散在高维空间，不保证每一层都能用一个人类词语准确命名。

这里的“逐层”可以理解为一支接力队：第一棒不必认出整只猫，只需把明显的边缘和方向传给下一棒；第二棒把若干边缘组合成弧线、纹理和角点；后面的层再把局部结构与位置关系组合起来。每一层只做相对简单的变换，许多层合在一起却能完成从数百万像素到类别判断的复杂任务。

不过，这个故事只是帮助入门。真实网络并不一定存在一个专门负责“猫耳朵”的神经元。一个概念常由许多神经元共同表示，一个神经元也可能参与表示多个概念。

## 传统特征工程：先把经验写进输入

在许多传统机器学习项目中，人会先设计特征。例如判断一封邮件是否为垃圾邮件，可以提取：

- 链接数量；
- 特定词语是否出现；
- 发件域名信誉；
- 大写字母比例；
- 附件类型。

对表格和业务规则明确的任务，特征工程很有价值：它能加入领域知识、减少数据需求，并让结果更容易解释。

传统机器学习不是一种单独的算法，而是一大类方法。常见成员包括线性回归、逻辑回归、决策树、随机森林和支持向量机。它们今天仍被用于销量预测、设备故障判断、风险分析和许多表格数据任务。

例如，学校想估计图书馆下周每天需要多少个自习座位。日期、星期几、天气、是否临近考试、过去几周的使用人数都已经是结构清晰的字段。此时先构造“距离考试还有几天”“是否为周末”等特征，再使用回归或树模型，可能比训练一个大型神经网络更合适。

| 对比角度 | 传统机器学习 | 深度学习 |
| --- | --- | --- |
| 常见输入 | 表格、统计记录、人工整理的特征 | 图片、声音、文字、视频，也可处理表格 |
| 特征从哪里来 | 经常由人根据经验设计和筛选 | 能在训练目标推动下逐层学习表示 |
| 数据需求 | 小数据上也可能有很好表现 | 通常更依赖大量且多样的数据 |
| 计算资源 | 训练和部署通常较轻 | 大模型训练可能需要大量算力和能源 |
| 解释难度 | 线性模型、浅层决策树较易说明 | 内部表示复杂，往往需要专门解释方法 |
| 何时优先考虑 | 规则清楚、表格数据、小样本、强调解释 | 输入复杂、规律高度非线性、数据与资源充足 |

表格只是一般规律，不是硬性边界。最终仍应在真正独立的数据上比较效果、成本和风险。

## 表示学习：让模型学习“什么信息值得保留”

深度神经网络可以直接接收像素、波形或 Token 向量，并在完成目标的过程中形成中间表示。这叫作**表示学习**。

好的表示会让后续任务更容易。例如，在原始像素空间里，两张角度不同的猫照片差异很大；在更高层表示中，它们可能因为共享耳朵、脸部轮廓和纹理模式而靠得更近。

可以把表示想成一张“对任务有用的地图”。在普通世界地图上，北京和上海按照地理位置相隔很远；在“城市气候特征地图”上，它们的位置会由温度、降水等数字决定。模型内部的表示也是如此：它不必保存我们习惯的名称，而是把与任务有关的关系编码成一组数字。

同一份数据在不同任务里需要不同地图。识别猫时，毛色也许不是关键；寻找走失的特定宠物时，毛色和花纹却很重要。表示从来不是脱离任务的“唯一真相”，它会受到数据和训练目标影响。

表示不是字典定义，而是一组分布式数字关系：

- 一个概念可能需要许多维度共同表达；
- 一个维度也可能参与多个概念；
- 相同输入在不同上下文中可能形成不同表示；
- 表示对训练数据和目标非常敏感。

## 端到端学习意味着什么

端到端学习让一个可训练系统直接学习从原始输入到目标输出的整体映射。例如：

> 语音波形 → 神经网络 → 文字

相比“人工设计声音特征 → 识别音素 → 组合词语 → 输出文字”的多段流水线，端到端方法可以共同优化各环节。

这就像从前由多组同学接力做一张海报：第一组只裁图，第二组只排字，第三组再统一修改；端到端训练则允许所有环节根据最终海报效果一起调整。优点是中间步骤可以相互配合，缺点是出错时更难立刻判断是哪一环造成的。

但端到端不等于“人不再重要”。人仍然负责：

- 决定问题是否值得做；
- 获得合法、代表性的数据；
- 设计训练目标和评估指标；
- 选择模型、资源与部署边界；
- 检查不同人群和场景中的错误；
- 为高风险输出设置复核与申诉机制。

## 深度学习为什么特别适合非结构化数据

图片、声音、文字和视频的信息量大，局部与整体之间关系复杂。深度模型可以利用不同结构逐层压缩与重组信息，因此在这些领域表现突出。

但对于样本很少的表格任务，树模型或线性模型仍可能：

- 训练更快；
- 需要更少算力；
- 更容易解释；
- 在正确验证下表现更好。

选择模型应看数据与任务，而不是追逐最流行的名字。

### 做选择时可以先问四个问题

1. **数据是什么形状？** 是几十列表格，还是数百万像素、长语音和文章？
2. **有多少可靠样本？** 一百条与一百万条，会支持完全不同的方案。
3. **为什么需要这个结果？** 是辅助推荐，还是会影响医疗、教育等重要决定？
4. **资源和时间有多少？** 手机端实时运行与数据中心离线训练，限制并不相同。

例如，“根据三年的温度表预测明天用电量”和“从卫星图片发现森林火点”都叫预测，但前者可以先尝试回归和树模型，后者更可能需要擅长视觉表示的深度网络。

## 迁移学习：已经学到的表示可以再利用

从零训练大型网络很昂贵。迁移学习先使用一个在广泛数据上训练的模型，再针对新任务进行适配。

例如，一个已经学习通用图像特征的模型，可以用较少校园植物照片微调成植物分类器。它不必从头学习所有边缘、纹理和形状。

把它想成一名已经会观察植物的转学生。他来到新校园后，不必重新学习“什么是叶片、花瓣和枝条”，只需熟悉本地常见物种的区别。这个针对新任务继续训练部分或全部参数的过程，常叫作**微调（fine-tuning）**。

迁移学习带来效率，也可能把原模型的数据偏差带入新任务。因此仍需重新评估。

例如，原模型很少见到冬季枯叶或本地特有植物，微调数据又只在春天拍摄，那么它在秋冬仍可能失效。复用能力不等于复用一份可靠性保证。

## 思考活动：信息在哪一层变得有用

选择一个任务，例如“识别自行车”。写出至少四级可能的表示：

1. 原始输入：像素；
2. 简单模式：边缘、颜色变化；
3. 局部结构：圆形车轮、细长车架；
4. 更高层关系：两个轮子与车架的空间组合；
5. 输出：自行车概率。

然后加入一张“只有一个车轮的局部照片”，讨论模型为什么仍可能识别，以及为什么也可能误判。

### 比一比两条路线

选择“判断一张操场照片中是否有人正在打篮球”，分别完成两套方案：

- 特征工程路线：你会人工提取哪些特征？篮球、篮筐、人物姿势、球场线分别可靠吗？
- 表示学习路线：需要收集哪些正例和反例？怎样覆盖室内外、远近、遮挡和不同服装？

再加入“只有篮球没有人”“有人投纸团”“人物站在篮筐旁”三张困难样本，检查两套方案可能利用了什么错误捷径。

### 给家长和教师的讨论建议

可以让学生先为一个熟悉物品写五条识别规则，再故意寻找反例。重点不是比较谁写得更聪明，而是体会两件事：人的领域经验非常有用，但现实中的例外可能写不完；自动学习特征可以减少人工设计，却更依赖数据覆盖和可靠评估。

## 常见误区

> [!NOTE]
> “自动学习特征”不是“无需理解数据”。如果训练数据把猫与沙发总是绑定在一起，网络可能自动学到错误捷径。

> [!NOTE]
> 更深的网络有更强表达能力，但也可能更难训练、更耗资源。残差连接、归一化和良好初始化等技术正是为解决这些工程问题而出现。

## 本课小结

- “深”表示多层信息变换；
- 表示学习让模型形成对任务有用的中间特征；
- 端到端减少人工拆分，但没有移除人的数据、安全和责任工作；
- 迁移学习能复用表示，也可能迁移偏差。
