# 深度与表示学习：模型怎样逐层“看见”复杂特征

## 本课目标

- 解释深度学习中的“深”指什么；
- 理解特征工程与表示学习的差异；
- 知道端到端学习减少了哪些人工步骤，又保留了哪些人的责任。

## “深”首先是计算结构，不是思想深刻

深度学习中的“深”，主要指神经网络包含多层信息变换。它不表示模型具有深刻思想，也不表示层数越多就必然越聪明。

多层网络可以把一个复杂映射拆成许多相对简单的步骤：

> 原始输入 → 简单局部模式 → 组合结构 → 更抽象表示 → 任务输出

例如图像网络在训练中可能形成：

> 像素变化 → 边缘与方向 → 纹理和轮廓 → 局部部件 → 完整对象

这是一种帮助理解的概括。真实网络中的特征分散在高维空间，不保证每一层都能用一个人类词语准确命名。

## 传统特征工程：先把经验写进输入

在许多传统机器学习项目中，人会先设计特征。例如判断一封邮件是否为垃圾邮件，可以提取：

- 链接数量；
- 特定词语是否出现；
- 发件域名信誉；
- 大写字母比例；
- 附件类型。

对表格和业务规则明确的任务，特征工程很有价值：它能加入领域知识、减少数据需求，并让结果更容易解释。

## 表示学习：让模型学习“什么信息值得保留”

深度神经网络可以直接接收像素、波形或 Token 向量，并在完成目标的过程中形成中间表示。这叫作**表示学习**。

好的表示会让后续任务更容易。例如，在原始像素空间里，两张角度不同的猫照片差异很大；在更高层表示中，它们可能因为共享耳朵、脸部轮廓和纹理模式而靠得更近。

表示不是字典定义，而是一组分布式数字关系：

- 一个概念可能需要许多维度共同表达；
- 一个维度也可能参与多个概念；
- 相同输入在不同上下文中可能形成不同表示；
- 表示对训练数据和目标非常敏感。

## 端到端学习意味着什么

端到端学习让一个可训练系统直接学习从原始输入到目标输出的整体映射。例如：

> 语音波形 → 神经网络 → 文字

相比“人工设计声音特征 → 识别音素 → 组合词语 → 输出文字”的多段流水线，端到端方法可以共同优化各环节。

但端到端不等于“人不再重要”。人仍然负责：

- 决定问题是否值得做；
- 获得合法、代表性的数据；
- 设计训练目标和评估指标；
- 选择模型、资源与部署边界；
- 检查不同人群和场景中的错误；
- 为高风险输出设置复核与申诉机制。

## 深度学习为什么特别适合非结构化数据

图片、声音、文字和视频的信息量大，局部与整体之间关系复杂。深度模型可以利用不同结构逐层压缩与重组信息，因此在这些领域表现突出。

但对于样本很少的表格任务，树模型或线性模型仍可能：

- 训练更快；
- 需要更少算力；
- 更容易解释；
- 在正确验证下表现更好。

选择模型应看数据与任务，而不是追逐最流行的名字。

## 迁移学习：已经学到的表示可以再利用

从零训练大型网络很昂贵。迁移学习先使用一个在广泛数据上训练的模型，再针对新任务进行适配。

例如，一个已经学习通用图像特征的模型，可以用较少校园植物照片微调成植物分类器。它不必从头学习所有边缘、纹理和形状。

迁移学习带来效率，也可能把原模型的数据偏差带入新任务。因此仍需重新评估。

## 思考活动：信息在哪一层变得有用

选择一个任务，例如“识别自行车”。写出至少四级可能的表示：

1. 原始输入：像素；
2. 简单模式：边缘、颜色变化；
3. 局部结构：圆形车轮、细长车架；
4. 更高层关系：两个轮子与车架的空间组合；
5. 输出：自行车概率。

然后加入一张“只有一个车轮的局部照片”，讨论模型为什么仍可能识别，以及为什么也可能误判。

## 常见误区

> [!NOTE]
> “自动学习特征”不是“无需理解数据”。如果训练数据把猫与沙发总是绑定在一起，网络可能自动学到错误捷径。

> [!NOTE]
> 更深的网络有更强表达能力，但也可能更难训练、更耗资源。残差连接、归一化和良好初始化等技术正是为解决这些工程问题而出现。

## 本课小结

- “深”表示多层信息变换；
- 表示学习让模型形成对任务有用的中间特征；
- 端到端减少人工拆分，但没有移除人的数据、安全和责任工作；
- 迁移学习能复用表示，也可能迁移偏差。
