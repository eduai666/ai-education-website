# 机器学习与深度学习：章节导读

![学生把多样的数据卡片送入多层神经网络，网络在另一端给出预测结果](./assets/machine-learning-hero.png)

## 这一章要解决什么问题

计算机为什么能认出照片里的猫、听懂一段语音，或者判断一封邮件是不是垃圾邮件？这些任务很难依靠几条固定规则完成。机器学习换了一种办法：不要求程序员写完所有判断条件，而是让模型从大量例子中调整参数，逐渐形成一套可以用于新数据的规律。

这一章不会把神经网络包装成“电子大脑”。我们会沿着一条可检查的技术链学习：

> **任务 → 数据 → 模型 → 预测 → 误差 → 参数更新 → 新数据评估**

当你能解释这条链，就能进一步判断一个 AI 系统为什么有效、为什么会错，以及宣传中的“准确率很高”是否真的可信。

## 适合谁学习

- 建议年龄：10—16 岁；
- 不要求会编程；
- 了解平均数、坐标系和简单函数会更容易，但不是必须；
- 建议总学习时间：90—140 分钟，可分多次完成。

## 学完后的能力目标

完成本章后，你应当能够：

1. 区分普通程序、机器学习与深度学习；
2. 用自己的话解释数据、特征、标签、模型、参数、训练和推理；
3. 描述神经网络一次训练循环中的四个关键步骤；
4. 解释训练集、验证集和测试集为什么必须分开；
5. 识别过拟合、数据泄漏、分布变化和偏差风险；
6. 面对一个新 AI 产品时，提出关于数据、目标与评估的关键问题。

## 阅读时请带着这五个问题

无论页面讲的是图片识别、推荐系统还是语言模型，都可以问：

1. 输入是什么？
2. 模型要输出什么？
3. 它根据什么反馈学习？
4. 我们用什么指标判断它做得好？
5. 新环境与训练环境不同以后，它还可靠吗？

> [!TIP]
> 不需要一次记住所有英文缩写。先理解“每个步骤解决什么问题”，再记术语，会轻松得多。
