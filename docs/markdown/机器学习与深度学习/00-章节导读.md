# 机器学习与深度学习：章节导读

![学生把多样的数据卡片送入多层神经网络，网络在另一端给出预测结果](/course-assets/machine-learning/machine-learning-hero.png)

## 这一章要解决什么问题

早晨，小雨拿起手机拍家里的猫，相册立刻把照片放进“宠物”分类；上学路上，她用语音输入发消息；午休时，邮箱又自动把一封“恭喜中奖”的邮件移进垃圾箱。三个功能看起来毫不相干，却都在做同一件事：**接收输入，根据学到的规律，给出输出。**

可是，程序员真的把每一种猫的样子、每一种口音和每一种诈骗话术都写进程序了吗？显然没有。现实中的情况多得写不完，于是人们换了一条路：准备许多例子，让模型从数据中调整内部数字，逐渐找到可用于新例子的规律。这就是机器学习的基本思想。

这一章要追踪一台“会学习的机器”从零开始工作的全过程：

> **任务 → 数据 → 模型 → 预测 → 误差 → 参数更新 → 新数据评估**

这不是一条只需背诵的流程。每一个箭头后面都有重要问题：任务说清楚了吗？数据能代表真实世界吗？模型究竟算了什么？错误怎样变成可以调整的信号？做过练习题之后，它能不能完成没见过的新题？

我们也不会把神经网络说成神秘的“电子大脑”。它首先是一组数学计算：输入经过许多带参数的小函数，得到预测；预测错了，训练算法就根据误差调整参数。多次重复以后，模型可能变得有用，但仍可能被错误数据、偶然背景或新环境骗过。

学到最后，你不仅应该知道 AI “能做什么”，还应该能解释它**为什么可能做到、证据够不够、哪里可能出错**。

## 适合谁学习

- 建议年龄：10—16 岁，核心故事与练习特别面向 10—14 岁读者；
- 不要求会编程，也不要求学过微积分；
- 只需会四则运算、百分数，并愿意跟着例子一步步推算；
- 可由学生自学，也可供家长共读或教师组织课堂活动；
- 建议总学习时间：190—250 分钟，可分多次完成。

遇到公式时，不必急着记符号。先问“这个数代表什么”“它为什么要这样变化”。公式只是把故事说得更准确的一种语言。

## 学完后的能力目标

完成本章后，你应当能够：

1. 用猫识别或垃圾邮件案例比较普通程序与机器学习；
2. 区分人工智能、机器学习与深度学习；
3. 用自己的话解释样本、特征、标签、模型、参数、训练和推理；
4. 算出一个简单神经元的输出，并说明权重、偏置和激活函数的作用；
5. 描述“预测—损失—反向传播—更新”的完整训练循环；
6. 解释训练集、验证集和测试集为什么必须分开；
7. 识别类别失衡、数据泄漏、过拟合、分布变化和偏差风险；
8. 面对“模型准确率达到 99%”这样的宣传，知道还应追问什么。

## 阅读时请带着这五个问题

无论页面讲的是图片识别、推荐系统还是语言模型，都可以问：

1. **输入是什么？** 是数字、图片、声音，还是文字？
2. **输出是什么？** 是类别、分数、下一段文字，还是一个动作？
3. **它根据什么反馈学习？** 正确标签、奖励，还是从数据自身构造的目标？
4. **怎样判断它做得好？** 指标是否真的代表我们在乎的结果？
5. **换一个人、地点或时间以后，它还可靠吗？**

例如，相册把猫认成狗，可能是训练图片太单一，也可能是照片太暗，还可能是模型过度依赖背景。提出这五个问题，能把一句模糊的“AI 出错了”变成一组可以调查的原因。

> [!TIP]
> 不需要一次记住所有英文缩写。每读完一课，试着不看正文，用自己的例子讲给别人听。能讲清“每一步解决什么问题”，比背出术语更重要。

## 开始前的小挑战

先判断下面三句话是否正确，学完本章再回来检查：

1. 机器学习就是把训练数据和答案全部存起来；
2. 神经网络层数越多、参数越多，就一定越聪明；
3. 模型在训练数据上全答对，也可能无法应对新数据。

参考判断：前两句错误，第三句正确。但真正重要的不是答案，而是你能否在后面的课程中找到证据，解释“为什么”。
