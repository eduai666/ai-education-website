# 动手实验与章节挑战：让模型在你的面前学会，也在你的面前犯错

## 实验目标

这组活动不要求编程。你将亲自观察：

- 数据数量与多样性怎样影响模型；
- 背景捷径怎样造成过拟合；
- 学习率与网络结构怎样改变训练过程；
- 为什么模型表现必须在新条件下测试。

## 实验一：用 Teachable Machine 训练手势分类器

工具：[Google Teachable Machine](https://teachablemachine.withgoogle.com/)

### 任务

训练模型识别“握拳”和“张开手掌”。

### 操作步骤

1. 建立两个类别；
2. 每类先采集 20 张图片；
3. 点击训练并在原位置测试；
4. 换角度、距离、背景和光线测试；
5. 再为每类补充更多变化后的图片；
6. 重新训练并比较结果。

### 变量控制

每轮只改变一个条件，才能知道是什么造成差异：

| 轮次 | 只改变的变量 | 其他条件 |
| --- | --- | --- |
| A | 每类样本从 20 增到 100 | 背景与角度保持一致 |
| B | 增加不同背景 | 样本数量大致相同 |
| C | 增加不同人的手势 | 背景和数量尽量相同 |

### 重点观察

- 原位置准确，换背景失效：模型可能学到了背景捷径；
- 一类总被误判：两类数据可能数量不平衡或姿势太相似；
- 置信度很高仍然错误：高概率不等于事实保证；
- 加入更多多样样本后改善：数据覆盖帮助泛化。

> [!WARNING]
> 只采集自己的手势，或在获得明确同意后采集他人数据。避免拍到姓名、证件、住址、账号、未公开作业和无关人员面部；实验结束后按平台说明删除项目和数据。

## 实验二：在 TensorFlow Playground 观察决策边界

工具：[TensorFlow Playground](https://playground.tensorflow.org/)

### 建议设置

1. 选择两类交错圆形或螺旋数据；
2. 先使用一个很小的网络；
3. 逐步增加隐藏层和神经元；
4. 分别尝试较小、适中和较大学习率；
5. 观察训练损失、测试损失与决策边界。

### 记录问题

- 网络太小时，边界是什么形状？
- 网络变复杂后，是否开始追随每个噪声点？
- 学习率很大时，损失是否震荡？
- 加入正则化以后，边界是否更平滑？

## 章节挑战：设计一个可信的小型机器学习项目

请选择“植物识别、垃圾分类、天气记录分析、图书主题聚类”中的一个，完成一页项目卡：

### 1. 问题

- 输入是什么？
- 输出是什么？
- 谁会使用结果？

### 2. 数据

- 从哪里获得？
- 每类需要哪些变化？
- 怎样保护隐私和版权？

### 3. 训练

- 使用哪种学习方式？
- 损失或反馈怎样定义？
- 哪些设置需要验证集选择？

### 4. 评估

- 测试集如何保证独立？
- 最重要的错误是哪一种？
- 哪些新环境可能让模型失效？

### 5. 责任

- 结果是否需要人工复核？
- 用户怎样知道系统有限制？
- 发现错误后怎样反馈和更新？

## 章节测验

### 第 1 题

模型在训练集上表现很好，在测试集上明显变差，最符合：

- A. 过拟合
- B. 推理
- C. 数据增强

**答案：** A。模型可能记住训练数据中的偶然细节。

### 第 2 题

反向传播的主要作用是：

- A. 自动收集更多数据
- B. 计算参数对损失的影响
- C. 把预测结果显示到屏幕

**答案：** B。优化器再根据这些梯度更新参数。

### 第 3 题

为什么测试集不应被反复用于调参？

**答案：** 因为调参会让开发过程逐渐适应测试集，它就不再是独立的新题，最终成绩会过于乐观。

### 第 4 题

深度学习中的“深”主要指什么？

**答案：** 神经网络包含多层信息变换，不代表拥有更深刻的思想或意识。

## 给家长和教师的话

陪伴实验时，最有价值的问题不是“准确率是多少”，而是：

- 哪些输入让模型犹豫？
- 哪些错误有共同特点？
- 改变背景以后为什么失效？
- 如果它用于真实学校，谁可能受到不公平影响？

让学生先预测结果、再操作、最后解释差异，比单纯追求训练成功更能形成 AI 素养。
