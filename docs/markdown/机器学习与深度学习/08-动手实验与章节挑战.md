# 动手实验与章节挑战：让模型在你的面前学会，也在你的面前犯错

## 实验目标

这组活动不要求编程。你将亲自观察：

- 数据数量与多样性怎样影响模型；
- 背景捷径怎样造成过拟合；
- 学习率与网络结构怎样改变训练过程；
- 为什么模型表现必须在新条件下测试。

真正的实验不是“点一下训练，看它能不能动”。开始前先写预测，过程中只改变一个主要条件，结束后再用证据解释差异。即使模型没有变好，只要你能说明发生了什么，这次实验仍然有价值。

建议准备一份电子表格或纸质记录表。每轮都保存相同的测试动作，并记录模型在哪些条件下犹豫或自信地犯错。不要为了得到漂亮结果而删除不符合预期的数据。

## 实验一：用 Teachable Machine 训练手势分类器

工具：[Google Teachable Machine](https://teachablemachine.withgoogle.com/)

### 任务

训练模型识别“握拳”和“张开手掌”。

### 操作步骤

1. 建立两个类别；
2. 每类先采集 20 张图片；
3. 点击训练并在原位置测试；
4. 换角度、距离、背景和光线测试；
5. 再为每类补充更多变化后的图片；
6. 重新训练并比较结果。

开始前先完成一句预测：

> 我认为只在同一背景采集的模型，换到新背景后会________，因为________。

测试时不要只挥动几次手就凭感觉判断。可以固定 20 次测试：握拳和张开手掌各 10 次，其中包括正对、倾斜、近距离、远距离和部分遮挡。记录每一次预测是否正确。

### 变量控制

每轮只改变一个条件，才能知道是什么造成差异：

| 轮次 | 只改变的变量 | 其他条件 |
| --- | --- | --- |
| A | 每类样本从 20 增到 100 | 背景与角度保持一致 |
| B | 增加不同背景 | 样本数量大致相同 |
| C | 增加不同人的手势 | 背景和数量尽量相同 |

### 实验记录模板

| 轮次 | 训练数据变化 | 测试条件 | 正确次数 / 总次数 | 最常见错误 | 我的解释 |
| --- | --- | --- | ---: | --- | --- |
| 基线 | 每类 20 张，同一背景 | 原位置 |  /20 |  |  |
| A | 每类增加到 100 张 | 原位置 |  /20 |  |  |
| B | 加入多种背景 | 新背景 |  /20 |  |  |
| C | 加入不同人的手势 | 新的人 |  /20 |  |  |

如果平台显示类别概率，也可以记录“预测正确但很犹豫”和“预测错误却非常自信”的样本。它们往往比普通正确样本更能暴露数据缺口。

### 重点观察

- 原位置准确，换背景失效：模型可能学到了背景捷径；
- 一类总被误判：两类数据可能数量不平衡或姿势太相似；
- 置信度很高仍然错误：高概率不等于事实保证；
- 加入更多多样样本后改善：数据覆盖帮助泛化。

这些是可能出现的现象，不是必须得到的标准答案。模型也可能因为摄像头自动调光、两轮随机初始化或动作不一致而产生不同结果。要重复几次，并诚实记录例外。

### 没得到预期结果时怎么排查

1. **训练时两类动作是否真的不同？** 如果两类都包含过渡动作，标签会互相矛盾。
2. **类别数量是否接近？** 一类样本远多于另一类，模型可能更偏向多数类。
3. **测试是否固定？** 每轮测试动作差别太大，就无法判断是哪项训练变化带来影响。
4. **是否一次改变太多条件？** 同时换背景、换人、换光线，很难找到原因。
5. **有没有把背景当答案？** 遮住手只保留背景，看看模型仍会不会坚定预测某一类。

> [!WARNING]
> 只采集自己的手势，或在获得明确同意后采集他人数据。避免拍到姓名、证件、住址、账号、未公开作业和无关人员面部；实验结束后按平台说明删除项目和数据。

## 实验二：在 TensorFlow Playground 观察决策边界

工具：[TensorFlow Playground](https://playground.tensorflow.org/)

### 建议设置

1. 选择两类交错圆形或螺旋数据；
2. 先使用一个很小的网络；
3. 逐步增加隐藏层和神经元；
4. 分别尝试较小、适中和较大学习率；
5. 观察训练损失、测试损失与决策边界。

### 记录问题

- 网络太小时，边界是什么形状？
- 网络变复杂后，是否开始追随每个噪声点？
- 学习率很大时，损失是否震荡？
- 加入正则化以后，边界是否更平滑？

### 记录一次模型“成长过程”

| 设置 | 训练损失 | 测试损失 | 边界形状 | 更像欠拟合、合适拟合还是过拟合 |
| --- | ---: | ---: | --- | --- |
| 很小的网络 |  |  |  |  |
| 增加隐藏层 |  |  |  |  |
| 很大学习率 |  |  |  |  |
| 增加正则化 |  |  |  |  |

先暂停运行，画出你预测的边界，再点击训练。预测不正确没有关系，重要的是用实际边界修正解释。若网络越来越复杂，训练损失继续下降而测试损失上升，就是过拟合的典型信号。

## 实验三：纸上模型审计

场景：学校准备使用一个模型预测“哪些学生需要额外学习支持”。

不要直接设计模型，先完成审计表：

| 问题 | 你的回答 |
| --- | --- |
| 这个目标能否被客观定义？ |  |
| 哪些数据属于敏感或不应使用的信息？ |  |
| “需要支持”由谁标注，学生能否申诉？ |  |
| 假正例和假负例分别会造成什么后果？ |  |
| 是否可能把家庭条件当成学习能力？ |  |
| 有没有不用预测个体也能提供普遍支持的方法？ |  |
| 最终决定必须由谁确认？ |  |

这个活动提醒我们：不是所有能建模的问题都应该建模。

### 角色讨论

四人一组，分别扮演学生、教师、模型开发者和家长。每个角色需要回答：

- 我最担心哪一种错误？
- 我需要看到什么证据才愿意试用？
- 如果预测错误，谁能纠正记录？
- 有没有风险更小、但同样能帮助学生的办法？

最后不要投票决定“模型好或坏”，而是写出允许试用必须满足的三个条件，以及明确禁止的一个用途。

## 实验四：没有网络也能做的“纸牌学习器”

这个实验只需要 24 张纸卡和几支彩笔。

### 准备数据

在每张卡上画一种虚构生物。它们可以有圆形或三角形身体、一个或两个角、条纹或圆点。秘密规则设为：“三角形身体并且有条纹的是甲类，其余是乙类。”只让负责出题的同学知道规则。

### 三种角色

- **数据员：**选择 12 张训练卡并标注甲/乙；
- **模型员：**只能观察训练卡，写下自己的判断办法；
- **测试员：**拿出 8 张未见过的测试卡，记录预测；剩余 4 张作为特别挑战。

第一轮，数据员故意让所有甲类都使用红色，模型员很可能把“红色”当成捷径。第二轮加入不同颜色的甲类和红色乙类，再让模型员修改规则。

### 记录与讨论

| 轮次 | 模型员学到的规则 | 训练集正确数 | 测试集正确数 | 发现的捷径 |
| --- | --- | ---: | ---: | --- |
| 1 |  |  /12 |  /8 |  |
| 2 |  |  /12 |  /8 |  |

这个活动不是在完整模拟神经网络，而是在体验训练集、测试集、标签、捷径和泛化。讨论：如果秘密规则本身会改变，测试结果还能维持多久？

## 章节挑战：设计一个可信的小型机器学习项目

请选择“植物识别、垃圾分类、天气记录分析、图书主题聚类”中的一个，完成一页项目卡：

### 1. 问题

- 输入是什么？
- 输出是什么？
- 谁会使用结果？

### 2. 数据

- 从哪里获得？
- 每类需要哪些变化？
- 怎样保护隐私和版权？

### 3. 训练

- 使用哪种学习方式？
- 损失或反馈怎样定义？
- 哪些设置需要验证集选择？

### 4. 评估

- 测试集如何保证独立？
- 最重要的错误是哪一种？
- 哪些新环境可能让模型失效？

### 5. 责任

- 结果是否需要人工复核？
- 用户怎样知道系统有限制？
- 发现错误后怎样反馈和更新？

### 最终交付物

项目卡最好包含：一段 100 字的问题说明、一张数据构成表、一张训练与测试流程图、一份至少包含两种错误的评估计划，以及一段明确的使用限制。不要把“使用先进模型”当成果，能解释为什么这样设计才是成果。

### 一个简短示例：校园植物识别

- 问题：帮助学生认识校内常见植物，不代替专家判断有毒植物；
- 数据：不同季节、天气、距离和生长阶段的照片，按植株而不是按照片随机划分；
- 评估：报告每种植物的正确数，特别记录相似物种之间的混淆；
- 限制：校园外物种、严重遮挡和夜间照片可能不可靠；
- 责任：低置信度时提示“无法判断”，不鼓励根据结果触摸或食用植物。

## 章节测验

### 第 1 题

模型在训练集上表现很好，在测试集上明显变差，最符合：

- A. 过拟合
- B. 推理
- C. 数据增强

**答案：** A。模型可能记住训练数据中的偶然细节。

### 第 2 题

反向传播的主要作用是：

- A. 自动收集更多数据
- B. 计算参数对损失的影响
- C. 把预测结果显示到屏幕

**答案：** B。优化器再根据这些梯度更新参数。

### 第 3 题

为什么测试集不应被反复用于调参？

**答案：** 因为调参会让开发过程逐渐适应测试集，它就不再是独立的新题，最终成绩会过于乐观。

### 第 4 题

深度学习中的“深”主要指什么？

**答案：** 神经网络包含多层信息变换，不代表拥有更深刻的思想或意识。

## 给家长和教师的话

陪伴实验时，最有价值的问题不是“准确率是多少”，而是：

- 哪些输入让模型犹豫？
- 哪些错误有共同特点？
- 改变背景以后为什么失效？
- 如果它用于真实学校，谁可能受到不公平影响？

让学生先预测结果、再操作、最后解释差异，比单纯追求训练成功更能形成 AI 素养。

## 项目评价量规

| 维度 | 4：证据充分 | 3：基本完整 | 2：部分完成 | 1：需要继续完善 |
| --- | --- | --- | --- | --- |
| 问题定义 | 输入、输出、使用者和错误后果都清楚 | 主要目标清楚，少量细节缺失 | 只写功能名称 | 目标含糊或无法评估 |
| 数据设计 | 覆盖关键变化，说明来源、标签和隐私 | 有训练与测试数据，考虑部分变化 | 有数据但代表性不足 | 不清楚数据从哪里来 |
| 实验方法 | 有预测、控制变量、重复测试和记录 | 有基本对照与记录 | 同时改变多项条件 | 只展示一次成功结果 |
| 证据解释 | 能用数据解释错误，并承认不确定性 | 能描述主要结果 | 只报告准确率 | 结论与证据无关 |
| 责任意识 | 明确限制、人工复核、反馈和退出机制 | 识别主要风险 | 只写“注意安全” | 没有考虑受影响的人 |

对 10—14 岁学生，评价重点应放在提出好问题、控制变量和解释证据，不必要求搭建复杂模型或追求最高准确率。
