# 机器学习与深度学习：术语表与参考资料

## 核心术语速查

不需要一次背完。遇到陌生词时，先找到它属于“数据、学习方式、模型、训练还是评估”，再回到对应页面查看完整例子。

### 数据与任务

| 术语 | 一句话解释 |
| --- | --- |
| 样本（example） | 数据集中的一条可被模型处理的记录，例如一封邮件 |
| 数据集（dataset） | 为某个任务收集并组织起来的许多样本 |
| 特征（feature） | 模型用来作出预测的信息，例如邮件中的词语和链接数量 |
| 标签（label） | 监督学习样本中给出的目标答案 |
| 分类（classification） | 预测属于哪个类别，例如猫、狗或兔子 |
| 回归（regression） | 预测连续数值，例如温度或用电量 |
| 聚类（clustering） | 没有标准类别时，按照相似性把样本分组 |
| 类别失衡（class imbalance） | 各类别样本数量差异很大，可能让总体准确率产生误导 |
| 数据泄漏（data leakage） | 训练或特征中混入了真正预测时不可能获得的信息 |

### 模型与学习方式

| 术语 | 一句话解释 |
| --- | --- |
| 模型（model） | 从输入映射到输出的数学关系 |
| 参数（parameter） | 训练过程中由算法调整的内部数字 |
| 权重（weight） | 控制某项输入或连接影响大小的一类参数 |
| 偏置（bias） | 调整神经元整体计算起点的一类参数；不要与社会偏差混淆 |
| 神经网络（neural network） | 由许多带参数的简单计算按层和连接方式组合成的模型 |
| 激活函数（activation function） | 为神经网络加入非线性的一种计算 |
| 表示（representation） | 模型内部用于表达数据及其关系的一组数字结构 |
| 监督学习（supervised learning） | 使用带有目标标签的样本学习 |
| 无监督学习（unsupervised learning） | 没有目标标签时寻找数据结构 |
| 强化学习（reinforcement learning） | 智能体根据行动得到的长期奖励调整策略 |
| 自监督学习（self-supervised learning） | 从数据本身构造预测目标，例如根据前文预测下一个 Token |
| 迁移学习（transfer learning） | 把一个任务学到的表示或参数用于另一个任务 |
| 微调（fine-tuning） | 在已有模型基础上，针对新数据和新任务继续训练 |

### 训练过程

| 术语 | 一句话解释 |
| --- | --- |
| 训练（training） | 利用数据和反馈调整模型参数 |
| 推理（inference） | 参数基本固定后，用训练好的模型处理新输入 |
| 前向传播（forward propagation） | 输入逐层计算并产生预测的过程 |
| 损失（loss） | 把预测错误程度表示成数值的评分规则 |
| 梯度（gradient） | 参数轻微变化时，损失变化的方向与快慢 |
| 反向传播（backpropagation） | 从输出误差出发，高效计算网络中各参数梯度的方法 |
| 优化器（optimizer） | 根据梯度更新参数的算法 |
| 学习率（learning rate） | 控制一次参数更新步幅的超参数 |
| 超参数（hyperparameter） | 由开发者选择、用于控制模型或训练过程的设置 |
| epoch（训练轮次） | 模型完整使用一遍训练集的一个轮次 |
| batch（批次） | 一次参与前向与反向计算的一小组样本 |

### 评估与可靠性

| 术语 | 一句话解释 |
| --- | --- |
| 训练集（training set） | 用于调整模型参数的数据 |
| 验证集（validation set） | 用于选择方案、超参数和停止时机的数据 |
| 测试集（test set） | 方案确定后，用于最终评价泛化能力的独立数据 |
| 泛化（generalization） | 对未见过但与任务相关的数据保持表现的能力 |
| 过拟合（overfitting） | 训练表现很好，但在新数据上明显变差 |
| 欠拟合（underfitting） | 连训练数据中的主要规律也没有学好 |
| 准确率（accuracy） | 全部样本中预测正确的比例 |
| 精确率（precision） | 被模型判为正例的样本中，真正例所占比例 |
| 召回率（recall） | 全部真正例中，被模型找到的比例 |
| 混淆矩阵（confusion matrix） | 同时列出真正例、假正例、假负例和真负例数量的表格 |
| 校准（calibration） | 检查模型给出的置信概率与长期实际正确比例是否相符 |
| 分布变化（distribution shift） | 使用时的数据规律与训练数据发生差异 |

### 常见架构

| 术语 | 一句话解释 |
| --- | --- |
| MLP / 多层感知机 | 由全连接层和非线性变换组成的基础网络 |
| CNN / 卷积神经网络 | 在不同位置复用局部观察窗口，擅长利用空间结构 |
| RNN / 循环神经网络 | 把历史状态随序列向后传递的网络 |
| LSTM / 长短期记忆网络 | 使用门控结构改善 RNN 的长期信息保留 |
| ResNet / 残差网络 | 用跨层捷径帮助信息和梯度通过深层网络 |
| Transformer | 以注意力机制为核心，建立不同位置之间的联系 |

## 九个常见说法，哪些需要修正

| 常见说法 | 更准确的理解 |
| --- | --- |
| 机器学习会自己思考 | 模型根据目标和数据调整参数，并执行数学计算 |
| 数据越多一定越好 | 重复、错误、偏斜或侵权数据可能让问题更严重 |
| 参数越多模型越聪明 | 能力还取决于数据、架构、训练、工具和评估 |
| 训练准确率 100% 就成功了 | 可能过拟合或发生数据泄漏 |
| 概率 90% 就几乎不会错 | 概率需要校准，分布变化后也可能失真 |
| 深度学习淘汰传统机器学习 | 表格、小数据和强解释需求下，传统模型仍有优势 |
| 注意力能完整解释模型 | 注意力权重只是复杂计算的一部分 |
| 模型没有情绪，所以没有偏见 | 偏见可以来自数据、标签、目标和部署方式 |
| 模型上线后不用再管 | 真实数据会变化，必须持续监测与更新 |

## 用五个问题结束这一章

以后遇到任何机器学习系统，先问：

1. 输入和输出分别是什么？
2. 数据从哪里来，代表谁，又漏掉了谁？
3. 模型优化的目标真的等于人的目标吗？
4. 测试是否独立，错误集中在哪些场景？
5. 上线后由谁监测、复核、申诉和承担责任？

如果你能持续追问这五件事，就已经从“会使用一个功能”走向“能够理解和判断一个机器学习系统”。

下一章将进入“大模型是如何工作的”。届时你会再次遇到本章的参数、训练、Transformer、泛化和高置信错误。区别在于，输入将主要变成 Token 序列，训练任务常与预测文字有关，模型规模也会明显增大。本章不是孤立的术语准备，而是理解大语言模型的地基。
