# 机器学习与深度学习：术语表与参考资料

## 核心术语速查

| 术语 | 一句话解释 |
| --- | --- |
| 样本（example） | 数据集中的一条可被模型处理的记录 |
| 特征（feature） | 模型用于作出预测的信息 |
| 标签（label） | 监督学习中的目标答案 |
| 模型（model） | 从输入映射到输出的数学关系 |
| 参数（parameter） | 训练过程中被调整的内部数字 |
| 超参数（hyperparameter） | 训练前或训练中由开发者选择的设置，如学习率 |
| 训练（training） | 利用数据和反馈调整参数 |
| 推理（inference） | 使用训练好的模型处理新输入 |
| 损失（loss） | 把预测错误程度表示成数值的规则 |
| 梯度（gradient） | 参数轻微变化时，损失变化的方向与速度 |
| 反向传播（backpropagation） | 高效计算网络中各参数梯度的方法 |
| 优化器（optimizer） | 根据梯度更新参数的算法 |
| epoch | 模型完整使用一遍训练集的一个轮次 |
| batch | 一次参与前向和反向计算的一小组样本 |
| 表示（representation） | 模型内部用于表达数据的数字结构 |
| 泛化（generalization） | 对未见过的相关数据保持良好表现 |
| 过拟合（overfitting） | 训练表现好但新数据表现差 |
| 欠拟合（underfitting） | 连训练数据中的主要规律也没学好 |
| 数据泄漏（data leakage） | 训练或特征中包含预测时不应获得的信息 |
| 分布变化（distribution shift） | 使用时数据规律与训练数据不同 |
| 迁移学习（transfer learning） | 把一个任务学到的表示用于另一个任务 |

## 九个常见说法，哪些需要修正

| 常见说法 | 更准确的理解 |
| --- | --- |
| 机器学习会自己思考 | 模型根据目标和数据调整参数，并执行数学计算 |
| 数据越多一定越好 | 重复、错误、偏斜或侵权数据可能让问题更严重 |
| 参数越多模型越聪明 | 能力还取决于数据、架构、训练、工具和评估 |
| 训练准确率 100% 就成功了 | 可能过拟合或发生数据泄漏 |
| 概率 90% 就几乎不会错 | 概率需要校准，分布变化后也可能失真 |
| 深度学习淘汰传统机器学习 | 表格、小数据和强解释需求下，传统模型仍有优势 |
| 注意力能完整解释模型 | 注意力权重只是复杂计算的一部分 |
| 模型没有情绪，所以没有偏见 | 偏见可以来自数据、标签、目标和部署方式 |
| 模型上线后不用再管 | 真实数据会变化，必须持续监测与更新 |

## 用五个问题结束这一章

以后遇到任何机器学习系统，先问：

1. 输入和输出分别是什么？
2. 数据从哪里来，代表谁，又漏掉了谁？
3. 模型优化的目标真的等于人的目标吗？
4. 测试是否独立，错误集中在哪些场景？
5. 上线后由谁监测、复核、申诉和承担责任？

如果你能持续追问这五件事，就已经从“会使用一个功能”走向“能够理解和判断一个机器学习系统”。
