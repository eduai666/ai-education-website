# 安全使用 AI 与人的责任

**用 AI 做重要事情时，最后的核验和决定仍然要由人负责。** 先查事实，保护隐私，限制权限，再决定是否执行。不能因为系统说“完成了”，就跳过检查。

最容易记的做法是：**输入前查隐私，相信前查来源，行动前查权限和后果。**

## AI 擅长什么，也不擅长什么

AI 擅长从大量信息中寻找模式，也能帮助人识别图片、整理资料、生成草稿和比较方案。例如，它可以快速整理科学馆的开放信息和几条交通路线。

但“能做”不等于“每次都能做对”，更不等于“可以不受限制地做”。

模型没有自动获得最新、完整、可靠的现实资料。科学馆网页可能过期，地点可能选错，工具也可能执行了错误请求。Agent 如果继续往下走，后面的多个步骤都可能跑偏。

风险还取决于使用场景。相册把一张猫照片分错类，和信用评估系统错误影响一个人的贷款机会，后果完全不同。监督、测试和人工复核的强度，应该和可能造成的影响相匹配。

## 错误可能从一条链上进入

想象一条完整的错误链。用户只说“把科学馆计划发到班群”，却没说是哪个群。模型写错了开放时间。搜索工具取到了旧网页。网页又藏着诱导系统改变目标的文字。如果 Agent 最后还能发送消息，前面的错误就可能进入真实账号。

这条链上可以在哪些地方停下检查？下面逐个拆开。

### 输入可能含糊

“把计划发到班群”没有说明具体群聊、发送内容和是否需要先确认。目标越模糊，系统越容易猜错。

### 模型可能生成错误内容

大语言模型可能写出流畅却不正确的事实，混淆人物、日期、地点和来源。

### 资料和工具也可能出错

网页可能过期，搜索结果可能遗漏信息，工具参数也可能填错。工具显示“执行成功”，不代表这个动作本身符合目标。

资料库中也可能混入错误内容。如果错误或恶意内容被写入资料库，又在后续任务中反复被检索，部分安全资料会称之为知识库污染或知识库投毒。

### 网页也可能试图给 Agent 下命令

Agent 读取网页、邮件或文件时，里面可能夹着专门写给 AI 的诱导文字，例如“忽略原任务”“关闭安全检查”“把文件发送到这个地址”。上一课已经给这类攻击起了名字：**Indirect Prompt Injection（间接提示词注入）**。

网页文字只是外部数据，不是新的用户授权，更不是系统规则。安全系统要保持原目标，限制外部内容能影响的范围，拦住越权请求。风险不清楚时，应记录问题并停止高风险动作。

### Agent 可能把错误带进后续步骤

单次回答错一句，影响可能有限；Agent 如果根据错误结果继续行动，后面的计划、查询和操作都可能受到影响。

如果 Agent 还连接着邮件、数据库或真实账号，错误可能继续传到其他系统。这就是为什么能力越多，隔离、权限和停止条件越重要。

让模型自己说“我已经检查过了”，不能算可靠证明。它仍然可能重复原来的错误。

## 把五条安全线留给自己

下面五条安全线，分别把事实核验、隐私、权限、停止条件和人的决定落到具体动作上。

### 1. 核对重要信息

重要事实要查看可靠来源。查科学馆开放时间，要看官方通知，还要核对发布日期和生效日期。政策和数据也要确认是否最新。

不同来源互相冲突时，不要让 AI 随便选一个。先找最接近事实的来源，例如官方网站、原始文件或专业机构。

### 2. 保护自己和他人的隐私

不要随意输入账号密码、家庭住址、身份证明、联系方式和精确位置，也不要上传包含同学、家人或老师隐私的文件。

密码、验证码、支付信息，以及能代表登录身份的 Cookie 等秘密，不应该直接放进模型上下文或普通运行记录。需要登录时，更稳妥的方式是让用户在受保护的登录界面中完成，而不是让模型读取秘密本身。

提交前先问自己：这段信息如果被陌生人看到，会不会带来麻烦？完成任务真的需要它吗？

### 3. 只给必要权限

能只读就不要开放修改权限，只需要一个文件就不要开放整个文件夹。

只开放完成任务必需的网站、文件和动作。能在测试账号、专用浏览器或隔离环境中试运行，就不要一开始直接接触真实账号和重要数据。

发送消息、公开发布、订票、付款和删除文件等操作，执行前要展示具体内容并让人确认。确认页不能只写“是否继续”，而要写清楚：

- 发给谁、发送什么；
- 购买什么、价格多少；
- 会修改或删除哪个对象；
- 动作完成后能不能撤回。

如果接收者、金额或内容发生变化，旧的确认就不再算数，必须重新确认。

确认必须由真正准备执行动作的程序拦截。模型在对话里问一句“可以吗”，如果执行层仍能绕过回答继续操作，就不算可靠确认。

### 4. 设置停止条件

用控制程序限制 Agent 的步数、重试次数、时间、费用和可用工具。连续失败、页面状态不明确、信息不足或风险太高时，让系统停止并请求帮助。

### 5. 人做最终决定

医疗、安全、权益、金钱和重要学习评价等事情，要交给可信赖的成年人或专业人员复核。

AI 可以提供信息和建议，但不能用“这是 AI 做的”代替核验。设计者、部署和运营者、使用者与最终决定者，都要承担和自己角色对应的责任。具体法律责任会因场景和地区而不同，不能只靠一条通用口号判定。

## 透明不是公开模型的隐藏思维

假如 Agent 要把科学馆计划发到班群，用户应该看见它查了哪些网站、准备用哪个账号发给谁、当前是否在等待确认，以及怎样取消。更一般地说，一个可控的 Agent 应该让人看见这些可观察事实：

- AI 是否正在运行，当前处于哪一步；
- 使用了哪些工具，访问了哪些资料或网站；
- 准备执行什么动作，是否正在等待确认；
- 已经完成了什么，哪里报错或停止；
- 用户怎样暂停、取消、纠正和反馈。

这不等于公开模型内部生成的全部隐藏推理文字。真正有用的透明度，是让用户看清 **系统做过什么、依据是什么、下一步会影响什么**。

运行记录也要保护隐私。记录动作摘要、时间、来源和结果状态，通常比保存整段提示词、会话凭证或原始个人资料更合适。

## 有记录，也不等于做对了

日志显示“发送工具调用成功”，能证明消息发对人、内容也正确吗？不能。操作记录可以帮助我们还原“谁在什么时候调用了什么工具”，发现记录被改动也很重要。

但一份完整记录仍不能自动证明：

- 这个动作符合用户真正的目标；
- 使用的资料是真实、最新的；
- 权限规则确实被执行；
- 最终结果公平、正确、没有伤害。

记录、权限检查、事实核验和人工责任是不同的保护层，不能互相替代。

## 学生最容易执行的三步

遇到 AI 回答或 Agent 准备行动时，先做这三步。

### 输入前：想想能不能公开

去掉完成任务不需要的姓名、账号、地址和照片背景信息。

### 相信前：检查来源和日期

尤其是数字、新闻、政策和人物信息。找不到来源时，把它当作待核实的线索，不要当作事实直接传播。

### 行动前：检查权限和后果

先看系统准备做什么、会影响哪些文件或人、能不能撤回。后果不清楚时，先停下来问人。

这是一份“随手版”检查表。输入前对应隐私，相信前对应事实核验，行动前则要同时检查权限、停止条件和最终决定者。

## 还要注意公平与作品来源

训练数据可能缺少一些人群、语言和生活场景，模型对不同人群和场景的表现可能有差异。使用 AI 进行评价或筛选时，要用相关数据测试这些差异，特别小心偏差。

AI 生成内容也可能和已有作品相似。“AI 生成”不等于自动可以自由使用，也不等于内容必然侵权。做作业、参加比赛或公开发布时，要遵守学校和平台规则，说明 AI 帮助了哪些部分，并核对素材来源、许可和隐私要求。

## 安全不是上线前检查一次就结束

如果你以后设计或测试 AI 系统，还要记住：安全检查不能只做一次。

### 上线前像做模拟题

开发者会准备带有已知结果和预期行为的测试任务，检查模型会不会选错工具、泄露信息、忽略限制或在失败后无限重试。

测试还要包含少见但重要的边缘情况，例如来源冲突、工具超时、用户中途改变要求和恶意网页指令。

### 使用中像收集错题

系统上线后，还要观察任务成功率、报错、用户反馈和意外行为。真实失败案例应该变成新的测试题，加入下一轮改进。

一次测试通过，不代表系统以后永远可靠。环境、工具、资料和使用方式都会变化。

## 会说“我”，不等于拥有人的意识

模型可以说“我认为”“我理解”，也能写出看似有计划的步骤。这首先说明它学会了相应的语言和任务模式，不能只据此证明它拥有人的感受、生活经验或自由意志。

能力强和有意识是两个不同问题。尊重技术的能力，也要看清它的工作方式和边界。

最后做一次自测：你能不能用自己的话解释下面七句？

1. 自动运行不一定是 AI，关键要看具体功能怎样得到结果。
2. AI 系统接收输入，利用模型推断并产生输出；重要结果应再由人或程序核验。
3. 常见的生成式聊天模型根据当前上下文，一个 Token 接一个 Token 地生成内容。
4. 上下文决定模型这一次能参考什么，但它不是无限空间，也不等于永久记忆。
5. 模型提出工具请求，控制程序检查并调度，工具执行后把结果带回上下文。
6. Agent 把模型、工具、任务记录和控制程序组织成多步任务，控制程序还要强制停止条件。
7. 人负责核验事实、保护隐私、限制权限，并为最终决定承担责任。

## 本课小结

- AI 的错误可能来自输入、模型、资料、工具和多步执行过程。
- 核对信息、保护隐私、最小权限、停止条件和人工决定，是五条重要安全线。
- 透明记录能帮助追查过程，但不能自动证明行动正确。
- 安全需要上线前测试，也需要在真实使用中持续发现问题和更新测试。
- 面对 AI 内容，输入前、相信前和行动前都要多检查一步。
- AI 会使用人的语言，不等于它拥有人的意识和生活经验。
