# 网站课程内容写作指南

这个目录是你的课程内容工作区。以后你只需要在 `docs/markdown` 中编写 `.md` 文件，我负责把内容整理、排版并接入网站。

你不需要编写 HTML、CSS、JavaScript、React 或 MDX，也不需要修改 `src`、`content` 等程序目录。

## 一、最简单的工作方式

1. 每一章新建一个 Markdown 文件。
2. 按照本指南下面的模板填写内容。
3. 图片放在 `docs/markdown/assets` 目录中，并在正文里标明使用位置。
4. 写完后告诉我文件名，以及希望我将它发布为哪一章。
5. 我会负责网站排版、导航、互动效果、运行检查、Git 提交和发布。

推荐使用 UTF-8 编码保存文件。

## 二、文件命名建议

建议使用“章节序号 + 简短名称”的形式：

```text
01-认识人工智能.md
02-机器学习与深度学习.md
03-大语言模型如何工作.md
04-什么是智能体.md
05-安全使用人工智能.md
```

文件名尽量简短，不要使用下面这些字符：

```text
\ / : * ? " < > |
```

## 三、标题层级

请尽量按照下面的层级编写：

```markdown
# 课程标题

## 本课目标

## 第一部分标题

### 第一部分中的小标题

## 第二部分标题

### 第二部分中的小标题

## 动手试一试

## 检查理解

## 本课小结

## 参考资料
```

注意：

- 每个文件只使用一个一级标题 `#`。
- 网站右侧“本页导航”主要根据二级标题 `##` 生成。
- 三级标题 `###` 用于某个部分内部的小主题。
- 不需要手动填写网页地址、锚点或编号，我会在接入网站时处理。

## 四、推荐的完整模板

新建课程时，可以复制下面的内容，然后替换方括号中的提示文字。

````markdown
# [课程标题]

## 课程信息

- 章节编号：[例如：第二章]
- 导航名称：[例如：机器学习与深度学习]
- 一句话简介：[用一两句话说明这节课讲什么]
- 适合年龄：[例如：10—14 岁]
- 预计学习时间：[例如：15 分钟]
- 是否需要互动练习：[需要 / 不需要 / 暂时不确定]

## 本课目标

完成本课后，学习者将能够：

- [目标一，尽量使用“解释、区分、判断、完成”等明确动词]
- [目标二]
- [目标三]

## [第一部分标题]

[正文内容。每段尽量表达一个主要意思。]

[下一段正文。段落之间空一行。]

### [小标题]

[小标题下的内容。]

> [!NOTE]
> [希望在网站中突出显示的重要说明。]

## [第二部分标题]

[正文内容。]

### [案例名称]

- 场景：[发生了什么]
- 输入：[系统接收了什么信息]
- 处理：[系统进行了什么判断或操作]
- 输出：[系统给出了什么结果]
- 思考：[这个案例希望学生思考什么]

## 动手试一试

### 练习 1：[练习名称]

- 练习目标：[希望学习者练习什么]
- 操作步骤：
  1. [第一步]
  2. [第二步]
  3. [第三步]
- 完成标准：[怎样算完成]
- 是否需要做成网页互动：[是 / 否 / 请你判断]

## 检查理解

### 第 1 题

**题目：** [题目内容]

**题型：** [单选题 / 多选题 / 判断题 / 开放题]

**选项：**

- A. [选项 A]
- B. [选项 B]
- C. [选项 C]

**正确答案：** [例如：B]

**答案解析：** [说明为什么这个答案正确，以及其他答案的问题。]

### 第 2 题

[按照相同格式继续添加。]

## 本课小结

- [最重要的知识点一]
- [最重要的知识点二]
- [最重要的知识点三]

## 课后挑战

[可选。说明学生课后可以完成的小任务。]
````

## 五、常用 Markdown 写法

### 普通段落

直接写文字即可。不同段落之间空一行：

```markdown
这是第一段内容。

这是第二段内容。
```

### 加粗和强调

```markdown
这是一个**需要重点理解的概念**。
```

不要连续加粗大段文字，只突出真正重要的关键词或结论。

### 无序列表

```markdown
- 第一项
- 第二项
- 第三项
```

### 有序步骤

```markdown
1. 完成第一步
2. 完成第二步
3. 检查结果
```

### 引用和提示

普通引用：

```markdown
> 这里是一段引用内容。
```

希望在网站中显示为提示卡片时，可以使用：

```markdown
> [!NOTE]
> 这里是补充说明或关键概念。

> [!TIP]
> 这里是学习建议或操作技巧。

> [!WARNING]
> 这里是安全提醒或容易出错的地方。
```

### 链接

```markdown
[链接名称](https://example.com)
```

参考资料尽量提供完整链接，并写清楚资料名称和用途。

### 图片

建议把图片放到：

```text
docs/markdown/assets/章节名称/
```

然后在 Markdown 中这样写：

```markdown
![图片中展示的内容](./assets/章节名称/图片文件名.png)
```

请使用能够说明图片内容的文字，不要只写“图片 1”。

如果暂时没有图片，可以先写一个图片需求：

```markdown
> [!IMAGE]
> 希望这里放一张“输入—模型—输出”流程示意图，风格简洁，适合 10—14 岁学生。
```

我接入网站时会和你确认是使用现有图片、制作图表，还是生成新图片。

### 表格

适合比较少量、简短的信息：

```markdown
| 类型 | 主要特点 | 例子 |
| --- | --- | --- |
| 普通程序 | 按明确规则执行 | 计算器 |
| 自动化 | 满足条件后自动行动 | 感应灯 |
| 人工智能 | 根据输入和模型进行推断 | 图片识别 |
```

如果单元格中需要写很长的段落，建议改用小标题或列表。

## 六、互动内容怎样写

你不需要实现网页互动，只需要描述清楚内容和规则。

### 分类练习

```markdown
## 分类练习：它属于哪一类？

分类选项：人工智能、自动化、普通程序

### 场景 1

- 场景：语音助手听懂提问
- 正确分类：人工智能
- 解释：它需要从语音输入中识别模式，并推断使用者可能表达的意思。

### 场景 2

- 场景：计算器计算乘法
- 正确分类：普通程序
- 解释：它按照明确的数学规则计算。
```

### 单选题

```markdown
### 第 1 题

**题目：** 下面哪一项更符合机器学习的特点？

**题型：** 单选题

**选项：**

- A. 只按照一条固定规则执行
- B. 从示例数据中寻找模式
- C. 每一次都随机选择答案

**正确答案：** B

**答案解析：** 机器学习模型会利用示例数据寻找可以用于新输入的模式。
```

### 开放题

```markdown
### 思考题

**题目：** 找出生活中一个可能使用机器学习的功能，并说明你的判断理由。

**参考方向：** 可以从输入、输出、是否需要识别模式等方面思考。
```

## 七、写作建议

- 先写清楚，再考虑写得生动；不用担心网页排版。
- 每一段尽量只表达一个主要意思。
- 第一次出现专业词语时，用生活化语言解释。
- 多使用具体案例，少堆叠抽象定义。
- 面向学生写作时，尽量直接使用“你”与学习者交流。
- 练习题除了写答案，也要写答案解析。
- 涉及事实、数据、定义和安全建议时，尽量记录来源。
- 不确定内容是否适合做成互动时，直接标注“请你判断”，我会设计实现方式。

## 八、不需要你处理的内容

下面这些工作由我负责：

- 网站页面地址和技术文件命名
- 左侧课程导航和右侧本页目录
- 上一课、下一课链接
- 字体、颜色、间距和响应式排版
- 提示卡片、流程图、测试题等网页组件
- 图片尺寸和网页资源路径
- 内容接入、运行检查和浏览器测试
- Git 提交、分支合并和推送

如果你的 Markdown 没有完全按照模板编写也没关系。只要标题、正文、题目、答案和资料来源能够区分清楚，我就可以协助整理。
