# 大模型是如何工作的：章节导读

![学生的问题被切成彩色Token，经过多层注意力网络后逐步展开为回答](/course-assets/large-models/large-model-hero.png)

## 这一章从一个误会开始

当 AI 几秒内写出文章、解释题目或生成图片时，人们常在两个极端之间摇摆：

- “它只是在资料库里搜索现成答案”；
- “它已经像人一样理解并思考一切”。

两种说法都过于简单。现代大模型首先仍是神经网络：它把训练数据中的复杂模式压缩进大量参数，再根据当前输入执行一连串概率计算。模型能够形成非常强的语言与多模态能力，却不会因此自动拥有可靠事实、现实经验、正确价值判断或无限权限。

先别急着往下读。想象下面这个场景：

> 小宇输入“请用三句话解释为什么会下雨”。几秒后，AI 不仅写出了答案，还把语言改成了小学生能读懂的版本。第二天，小宇把“下雨”换成“彩虹”，AI 又能回答一个训练材料里未必原样出现过的问题。

你认为它最像下面哪一种情况？先在心里投一票：

| 你的选择 | 这种猜想意味着什么 |
| --- | --- |
| A. 在巨大的资料库里找到现成答案 | 每个问题都应该对应一段已经保存好的文字 |
| B. 把见过的句子剪碎后重新粘贴 | 新答案主要是旧句子的拼接 |
| C. 根据前文不断预测接下来最合适的文字 | 回答是一步一步生成的，每一步都有多个可能 |
| D. 像人一样先形成完整想法，再把想法翻译成文字 | 模型内部应该有与人相同的经验和意识 |

本章不会立刻公布一个只有一句话的“标准答案”。你会亲自追踪一句话怎样被切分、计算和续写，再回来判断：哪些选项抓住了部分事实，哪些又把事情说得过头了。

### 三个贯穿全章的追问

学习每一课时，都可以带着三个问题：

1. **信息变成了什么？** 是 Token、向量、概率，还是外部工具返回的结果？
2. **这一步是谁完成的？** 是神经网络、分词器、搜索系统，还是人？
3. **哪里可能出错？** 是训练数据有问题、模型选错下一步，还是工具和权限出了问题？

本章用一条清晰的主线拆开这个过程：

> **文字 → Token → 向量与位置 → Transformer → 下一个 Token 概率 → 逐步生成 → 对齐与工具 → 真实产品**

如果把大模型想成一座“文字工厂”，全章机制图可以先这样读：

```text
你输入一句中文
      │
      ▼
分词器切成 Token，并换成编号
      │
      ▼
嵌入层把编号换成向量，再加入位置信息
      │
      ▼
多层 Transformer 让各位置交换信息
      │
      ▼
模型给“下一个 Token”列出一张概率表
      │
      ▼
选出一个 Token，接回原文，再重复整个过程
      │
      ├── 经过指令微调与偏好对齐 → 更像会帮助人的助手
      ├── 接上搜索、计算器和软件工具 → 能处理更新信息和执行任务
      └── 接上图像、声音或机器人系统 → 进入多模态与物理世界
```

这张图暂时不要求全部看懂。每学完一课，就回来找到对应的一格；到章节末尾，你应该能从上到下解释整条链路，并指出每一格的能力边界。

## 适合谁学习

- 建议年龄：11—16 岁；
- 建议先完成“机器学习与深度学习”章节；
- 不要求会编程或高等数学；
- 建议总学习时间：240—320 分钟，可拆成多次学习。

## 学完后的能力目标

你应当能够：

1. 解释大模型与普通神经网络的关系；
2. 描述文字从 Token 到下一个 Token 的完整流程；
3. 用直观语言说明自注意力中的 Query、Key 和 Value；
4. 区分基础模型、聊天助手、搜索系统和 Agent；
5. 解释扩散生成、多模态和具身智能的基本思路；
6. 针对幻觉、隐私、版权、资源消耗和行动权限提出检查问题。

## 本章的三条边界

> [!NOTE]
> **表现像理解，不等于每次都理解正确。** 对重要结论仍需证据、计算、实验或可靠来源。

> [!NOTE]
> **模型不等于产品。** 日常聊天助手还连接了系统指令、搜索、工具、记忆、安全检查和界面。

> [!WARNING]
> **能生成建议，不等于有权采取行动。** 发送消息、付款、删除文件、提交作业和控制设备都应有明确权限与人工确认。
