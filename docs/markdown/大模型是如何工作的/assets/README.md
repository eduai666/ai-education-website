# 图片与图表说明

本目录保存“大模型是如何工作的”章节配图。正文使用相对路径引用。

| 文件 | 类型 | 用途与来源说明 |
| --- | --- | --- |
| `large-model-hero.png` | PNG 主视觉 | 使用 OpenAI 内置图像生成能力制作的原创教学插图，无品牌与可识别文字 |
| `token-pipeline.svg` | SVG 教学图 | 本项目原创绘制；概念参考 Google LLM 课程与 Hugging Face Tokenizers 课程 |
| `attention.svg` | SVG 教学图 | 本项目原创绘制；概念参考《Attention Is All You Need》 |
| `next-token.svg` | SVG 教学图 | 本项目原创绘制；说明自回归生成与候选概率 |
| `training-stages.svg` | SVG 教学图 | 本项目原创绘制；说明预训练、指令微调、偏好对齐和产品系统 |
| `diffusion.svg` | SVG 教学图 | 本项目原创绘制；概念参考 DDPM 与潜在扩散研究 |
| `multimodal-agent.svg` | SVG 教学图 | 本项目原创绘制；说明多模态输入、Agent 工具和物理世界行动 |

生成主视觉时使用的最终提示词摘要：面向 10—14 岁读者，以“学生问题 → 彩色 Token → 多层透明 Transformer 与注意力连线 → 逐 Token 展开的回答”为叙事主线，并用小型视觉符号暗示图像、声音和代码；精致 3D 编辑插画风格，不含文字、品牌、水印、机器人或大脑图标。
