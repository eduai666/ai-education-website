# 图片、视频与多模态生成：模型怎样从文字走向视觉和声音

## 本课目标

- 解释扩散生成与潜在空间；
- 说明视频生成为什么比单张图片更难；
- 理解多模态模型怎样对齐文字、图像和声音；
- 识别生成媒体的真实性、版权和隐私风险。

## 图片不能简单按像素逐个“续写”

高清图片包含数百万像素，而且远处像素共同决定物体、透视和光照。逐像素生成既慢，也难保持全局结构。

当前视觉生成存在多种路线，其中扩散模型及流模型是一条重要主线：从随机状态出发，在文字或图片条件引导下，逐步修正为合理画面。

先做一个想象实验：把一张清晰的橘猫照片打印出来，再一层层撒上黑白雪花点。开始时还能看见耳朵和尾巴，继续加噪后只剩模糊色块，最后看起来就像没有信号的旧电视。

如果只看最后一张噪声图，人几乎不可能找回原猫。扩散模型却通过大量训练样本，学习“在某种噪声程度下，朝哪个方向修改会更像训练数据中的合理图片”。生成时，它从一团新的随机状态出发，重复许多次这种小修正。

这不是先在资料库里挑一张猫图，再一点点把遮挡擦掉。初始噪声通常没有藏着一张完整的猫；画面结构是在条件引导和多步计算中逐渐形成的。

## 扩散模型的直观过程

训练时，模型学习不同噪声程度下应该怎样修正。生成时则从随机噪声开始，多次调用网络：

> 随机噪声 → 粗略色块 → 主体轮廓 → 材质与细节 → 最终图片

![文字条件引导扩散模型把随机噪声逐步修正成图片](/course-assets/large-models/diffusion.svg)

训练不一定真的每次完整走完全部加噪步骤。常见做法是随机选择一个噪声等级，直接给训练样本加入相应噪声，再让网络预测噪声、速度或修正方向。

### 训练时，模型究竟练习什么

用一张配有文字“戴蓝色围巾的橘猫”的训练图来说明，一次练习大致是：

1. 编码器把图片转换成像素或潜在表示；
2. 系统随机选择一个噪声等级，例如“已经有 60% 看不清”；
3. 按这个等级直接加入已知的随机噪声；
4. 网络同时看到带噪表示、噪声等级和文字条件，预测应该去掉的噪声或移动方向；
5. 系统把预测和已知目标比较，计算误差并更新参数。

下一次练习可能选 10% 噪声，也可能选 95% 噪声。经过大量图片和大量噪声等级，网络才逐渐学会从“几乎全乱”到“只差一点细节”的不同修正方法。

生成一张新图时，系统才会真的从随机状态出发，多次应用学到的修正：

| 阶段 | 画面可能出现的变化 | 模型此时更关心什么 |
| --- | --- | --- |
| 初始 | 几乎是随机噪声 | 大致构图和整体颜色往哪里发展 |
| 早期 | 出现暖色区域和猫的粗略轮廓 | 主体位置、姿势、背景布局 |
| 中期 | 围巾、耳朵、雪地逐渐可辨 | 对象之间的关系和主要属性 |
| 后期 | 毛发、眼睛、阴影更加清楚 | 局部纹理与细节一致性 |

“早期只管构图、后期只管毛发”也不是不可改变的硬规则，各阶段会相互影响。这张表是帮助观察生成过程，而不是把网络内部划成四个固定部门。

## 文字怎样控制画面

提示词先由文本编码器转换为向量。图像网络在每一步生成中通过交叉注意力等机制参考文字表示。

提示词“戴蓝色围巾的橘猫坐在雪地里，儿童绘本风格”同时提供：

- 主体：橘猫；
- 属性：蓝色围巾；
- 场景：雪地；
- 风格：儿童绘本。

它不是把这些词直接贴在像素上，而是改变生成过程中哪些方向更符合条件。

文字编码器先把提示转换成向量。生成网络通过交叉注意力等机制，在不同位置和不同阶段参考这些文字表示。可以把提示拆成一张“约束清单”：

| 提示部分 | 需要在图中落实的关系 |
| --- | --- |
| 一只橘猫 | 数量为一，主体与颜色匹配 |
| 戴着蓝色围巾 | 围巾属于猫，位置在颈部附近，颜色为蓝色 |
| 坐在雪地里 | 姿势与场景合理，脚部和雪地有接触关系 |
| 儿童绘本风格 | 线条、色彩和材质共同符合风格描述 |

模型通常比单独生成一个对象更难处理**数量和关系**。例如“一只猫追两只球”“红杯在蓝盒左边”“每个孩子都拿一把不同颜色的伞”，要求模型同时保持多个对象、数量、属性和空间关系，任何一项都可能错位。

因此，写得很长不一定更好。一个有效提示要让主体、动作、场景和重要关系清楚，避免互相矛盾。生成后还要逐项核对，而不是因为整体漂亮就忽略细节。

## 为什么在潜在空间工作

直接在高清像素空间反复计算代价很高。潜在扩散模型先用编码器把图片压缩到更小的潜在表示，在这个数学空间中生成，再由解码器还原为像素。

潜在表示不是普通缩略图。它由多个通道共同保存结构、纹理和语义信息。

可以把像素空间想成一面由数百万块马赛克组成的墙。若每次修改都直接搬动每块马赛克，代价很高。潜在空间更像一张压缩的设计图：它不只是把图片缩小，而是让神经网络用较少的数字保存重要视觉结构。模型先在设计图上反复修改，最后再由解码器铺回高清马赛克。

压缩会提高效率，也会造成限制。太小的文字、精密几何、规则表格和复杂纹理可能在压缩与还原中丢失。即使潜在表示看起来合理，解码成像素后仍可能出现边缘或文字错误。

现代系统也可能采用：

- Diffusion Transformer；
- 流匹配或整流流；
- 把图片表示为离散视觉 Token 并自回归生成；
- 在统一多模态网络中共同理解和生成文字与图片。

## 为什么相同提示会生成不同图片

随机种子改变初始噪声，因此主体位置、细节、构图可能变化。引导强度、采样步骤、模型版本、画幅与参考图也会影响结果。

高提示词遵循度不等于高真实性。模型可能在视觉上满足“像”，却违反文字、空间或物理细节。

随机种子可以理解成“从哪一团随机材料开始”。固定模型、提示、画幅和生成设置时，同一个种子有助于复现实验；换一个种子，模型会从另一团噪声出发，构图和细节就可能不同。

但种子不是图片编号。不同平台、模型版本或算法实现中，即使输入相同种子，也未必得到同一张图。升级模型后，原来的种子还可能对应完全不同的结果。

小林连续生成四张“蓝围巾橘猫”后，发现三张围巾是蓝色，一张却变成紫色；一张有两条尾巴。正确结论不是“第四个种子不好”，而是：生成是概率过程，提示约束不是硬性绘图程序，每张结果都需要检查。

## 视频为什么更难

一段 5 秒、每秒 24 帧的视频有 120 帧。模型不仅要让每帧合理，还要保持：

- 人物身份和衣着一致；
- 物体形状、位置和遮挡连续；
- 动作速度自然；
- 镜头运动一致；
- 事件因果顺序合理；
- 声音与画面对齐。

视频模型会处理时空小块或潜在视频表示，同时学习空间结构和时间变化。系统也可能先生成低分辨率短片，再提高帧率、分辨率并生成声音。

即使视频看起来有“物理感”，也不表示模型掌握了精确物理定律。物体仍可能凭空消失、穿透、恢复或改变身份。

### 120 张好图片，还不一定是一段好视频

设想一个 5 秒镜头：一个穿黄色雨衣的孩子把红球抛给穿蓝衣服的朋友。第 1 帧和第 120 帧都画得很漂亮，视频仍可能失败：

- 到第 20 帧，黄色雨衣突然变成绿色；
- 球被手挡住几帧后，重新出现时变成两个；
- 球先落地，接着又无缘无故回到空中；
- 镜头向右移动时，背景建筑却向错误方向滑动；
- 两个人的脸在快速动作中互换；
- 音效比球落地提前半秒。

图片主要要保持同一时刻的空间关系；视频还要保持跨时间的身份、运动和因果。模型常把压缩视频切成**时空小块**：每个小块不仅表示画面的一个区域，还覆盖一小段时间。Transformer 或其他生成网络让这些小块交换信息，以学习“这个物体前一刻在哪里，下一刻应该怎样变化”。

一些系统会先生成短而模糊的视频，再逐步提高帧率和分辨率；另一些系统在统一的时空潜在表示中生成整段内容。无论路线怎样，时间越长、对象越多、遮挡越复杂，保持一致通常越困难。

“看起来符合日常经验”也不等于模型学会精确物理。训练视频让它熟悉水流、走路、碰撞的常见外观，但罕见情况和严格数值关系仍可能错误。生成视频不应直接当作物理实验结果或新闻证据。

## 多模态模型怎样连接不同信息

文字、图片、声音和视频原始形式不同：

- 文字是 Token 序列；
- 图片是像素网格或视觉小块；
- 声音是波形或频谱；
- 视频同时包含空间和时间。

模型会用相应编码器、分块或离散化方法转换为向量，再通过配对数据学习模态对齐：

- 图片与说明文字；
- 语音与转写；
- 视频与字幕；
- 图表与问答；
- 机器人画面、指令与动作。

多模态扩大了能力，也扩大了错误面：模型可能看错小字、读错坐标、混淆相似物体、误判声音来源或颠倒视频事件。

### “看见红伞”与读到“红伞”怎样连起来

假设训练样本包含一张街景和说明：“一个孩子举着红伞过马路。”视觉编码器把图片切成视觉小块，文字分词器把说明切成 Token。训练目标会推动系统把图中的孩子、红色区域、伞的形状与相应文字建立可利用的联系。

只有“图片—说明”还不够覆盖所有能力。为了回答图表问题，需要“图表—问题—答案”；为了听懂语音，需要“音频—转写或语义”；为了理解视频顺序，需要带时间信息的视频描述；为了让机器人行动，还需要“画面—指令—状态—动作”的配对轨迹。

对齐不是给每个像素贴上中文标签，而是让不同模态的表示能在任务中相互对应。同一个模型也可能对常见动物和大标题识别很好，却看错药盒角落的小字、折线图的刻度或两段很相似的声音。

遇到多模态回答时，可以把问题拆开验证：

1. 模型有没有看见正确区域？
2. 它有没有读对数量、文字和坐标？
3. 它的语言结论是否真的由图像或音频支持？
4. 图片、音频或视频本身是否来自可靠来源？

## 生成图片的四层核验

1. **提示符合：**是否满足主体、关系、数量和风格？
2. **内部一致：**手、文字、阴影、反射、遮挡和结构是否合理？
3. **来源与授权：**训练、参考图、人物肖像和品牌元素是否有合法依据？
4. **传播语境：**是否会让人误以为真实事件？是否清楚标注为生成内容？

> [!WARNING]
> 不要用真实同学、教师或公众人物的脸制作误导性内容；不要上传未经同意的私密照片；不要把生成图冒充新闻、证据或他人作品。

## 小活动：固定提示，只改变一个变量

选择合规图片生成工具，固定提示：

> 一座建在巨树枝干上的未来图书馆，傍晚，暖色灯光，儿童绘本风格。

依次只改变：

- 随机种子；
- “傍晚”为“清晨”；
- 横向画幅为纵向画幅；
- 加入“不要出现人物”。

记录哪些变化符合预期、哪些无关部分也被改变，以及画面中有哪些不合理结构。

## 本课小结

- 扩散与流模型从随机状态逐步形成图像；
- 潜在空间降低高清生成成本；
- 视频还要保持跨时间一致性与运动关系；
- 多模态模型把不同信息转换为可共同处理的表示；
- 视觉逼真不等于真实发生，必须检查来源、授权和传播语境。
