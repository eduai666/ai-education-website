# 什么是大模型：“大”不只是参数数量

## 本课目标

- 解释大模型、基础模型和大语言模型；
- 区分参数量、激活参数量、训练数据与计算量；
- 避免用参数数量直接给模型能力排名。

## 大模型没有跳出神经网络

大模型仍可以写成一个带参数的函数：

$$
\hat{y}=f(x;\theta)
$$

它仍然依靠矩阵运算、非线性变换、误差计算和参数更新。变化主要在规模与用途：

- 参数更多，模型能表达更复杂的关系；
- 训练数据更广，覆盖文字、代码、图片、声音等多种内容；
- 训练计算量更大；
- 不只学习一个狭窄任务，而是形成可迁移到许多任务的基础能力；
- 经过适配后，同一模型可以完成问答、总结、翻译、编程或工具调用。

**基础模型（foundation model）**强调“先在广泛数据上预训练，再适配许多下游任务”。它没有一个全世界统一的参数门槛。

## 大语言模型只是大模型家族的一员

| 类型 | 常见输入 | 常见输出 |
| --- | --- | --- |
| 大语言模型（LLM） | 文字、代码 | 文字、代码 |
| 视觉语言模型（VLM） | 图片 + 文字 | 文字或结构化答案 |
| 多模态模型 | 文字、图片、声音、视频 | 一种或多种模态 |
| 图像/视频生成模型 | 提示词、参考图、视频片段 | 图片或视频 |
| 世界模型 | 当前状态、历史与动作 | 对未来状态的预测 |
| 视觉—语言—动作模型（VLA） | 画面、指令、机器人状态 | 动作或动作序列 |

## 参数到底是什么

参数是训练中被调整的数字。它们共同决定信息怎样表示和传递、注意力怎样计算、下一个 Token 概率如何变化。

> **一个参数不等于一条知识，也不等于一个神经元。**

知识和能力通常分布在许多参数的共同作用中。同一个参数也可能参与多个语言、知识和任务模式。

### 数量级怎样理解

如果一个模型有 700 亿参数，并用每个参数 2 字节的 16 位格式保存，仅权重就约需 140 GB。真实运行还要存储中间激活、上下文缓存和程序数据。

量化可以把权重压缩到 8 位或 4 位，让模型在更小设备上运行，但可能在精度、速度、兼容性和能耗之间产生新的取舍。

## 稠密模型与混合专家模型

### 稠密模型

处理每个 Token 时，大部分参数都参与计算。总参数量和每步实际计算量关系较直接。

### 混合专家模型（MoE）

模型内部有多个“专家”模块，路由器为每个 Token 选择其中少数模块。于是需要区分：

- **总参数量：**整个模型拥有的全部容量；
- **激活参数量：**处理当前 Token 时实际参与主要计算的参数。

“专家”只是网络模块，不保证某个模块固定负责数学、历史或中文。路由与专家能力是在训练中形成的。

## 更大为什么可能更强

在足够数据和计算支持下，更大模型通常能够：

- 形成更丰富的表示；
- 利用更长上下文；
- 在更多任务之间迁移；
- 从少量示例或指令中适应任务。

但更大也带来：

- 更高训练和推理成本；
- 更难复现实验；
- 更复杂的部署；
- 更大的数据、版权与环境影响；
- 更难完整解释内部机制。

## 参数、数据和计算必须配合

模型不能只增加参数却不给足数据，也不能只堆数据却没有相应计算。扩展规律研究说明，参数规模、训练 Token 数和计算预算之间需要合理配比。

模型质量还受到：

- 数据清洗和去重；
- 架构与优化算法；
- 指令微调和偏好对齐；
- 推理时使用多少额外计算；
- 是否连接搜索、代码和其他工具；
- 评估是否代表真实任务。

所以“模型 A 参数更多”不能单独推出“模型 A 在所有任务上更好”。

## 算力、能源与水怎样进入讨论

大规模训练让许多 GPU 并行工作。GPU 小时表示“GPU 数量 × 运行小时”，但不同芯片、利用率、架构和统计边界不能直接横比。

电力用于计算和数据中心设备，冷却系统可能直接或间接用水。讨论环境影响时要说明：

- 统计的是训练还是长期推理；
- 只算芯片功率还是整个数据中心；
- 使用地点法还是市场法碳排口径；
- 说的是取水量还是净耗水量；
- 地点、季节和电力来源是什么。

醒目的单个数字没有边界说明，往往会造成误导。更负责任的方向包括高效算法、模型压缩、适配任务的小模型、低碳电力和更透明披露。

## 检查理解

**题目：** 一个 MoE 模型总参数 5000 亿，每个 Token 激活 300 亿。能否说每次生成都使用了全部 5000 亿参数？

**答案：** 不能。总参数表示整体容量，激活参数表示一次处理主要参与计算的部分，两者必须分开报告。

## 本课小结

- 大模型仍然是神经网络；
- “大”同时涉及参数、数据、计算和能力覆盖；
- 参数不是独立知识条目；
- MoE 要区分总参数与激活参数；
- 能力不能只用参数量评价，资源数字也必须说明口径。
