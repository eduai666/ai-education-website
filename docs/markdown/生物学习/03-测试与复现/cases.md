## 3. 每次真机运行必填的环境

- Run ID、源代码 Git commit 和 `repro-inputs-v1.json` 的 SHA-256；
- 设备厂商、完整型号、内存容量与选择该设备作为测试机的理由；
- 操作系统名称、系统版本和构建号；
- 浏览器名称、完整版本、WebGL renderer 与 GPU 信息；
- CSS 视口宽高、屏幕方向和 DPR；
- 网络类型、运营商、测试地点、`saveData` 状态和弱网整形参数；
- 冷缓存或热缓存、开始和结束时间，以及测量工具的精确版本；
- 每个步骤的实际结果、状态、证据文件和执行人匿名角色。

如果缺少型号、浏览器版本或原始证据，该次结果只能记为调试线索，不能作为发布验收。

## 4. `UI-001-REAL-TOUCH`：真实触屏选择

| 字段 | 内容 |
| --- | --- |
| 级别 | P0 |
| 负责人 | 未参与开发的真机测试者 |
| 当前状态 | **待人工执行** |
| 前置条件 | 一台真实手机或平板；清除该站点数据后直接输入路由地址 |
| 证据 | 设备信息截图、连续录屏、步骤结果表 |

固定步骤：

1. 不启动 3D，依次轻触“细胞膜”、“细胞核”和“线粒体”外部按钮。
2. 每次记录按钮选中文字、知识卡名称和 `data-selected-structure`；三者必须指向同一 ID。
3. 主动轻触“启动 3D”，等到明确的 3D 就绪状态。
4. 分别轻触三个可见的 3D 结构；选择成功时，外部按钮、文字和轮廓提示必须同步，且不只依赖颜色。
5. 轻触空白区域，确认页面不报错；再快速轻触三个外部按钮，最终知识卡必须对应最后一次选择。

通过条件：五个步骤全部符合预期，无误触后残留状态、无浏览器错误，且证据可定位到指定提交。

## 5. `UI-002-REAL-GESTURE`：真实手势与复位

| 字段 | 内容 |
| --- | --- |
| 级别 | P0 |
| 当前状态 | **待人工执行** |
| 前置条件 | 同 `UI-001-REAL-TOUCH`，并已成功启动 3D |
| 证据 | 连续录屏、步骤结果表 |

固定步骤：

1. 用单指水平拖动约屏幕宽度的四分之一，确认模型旋转而页面不误滚动。
2. 用双指先拉开、再合拢，确认镜头在规定距离范围内缩放。
3. 选择线粒体，再轻触“复位视角”。
4. 确认镜头、模型姿态和选中项恢复固定初始状态，选中 ID 为 `cell-membrane`。
5. 轻触“返回 2D”，确认三张知识卡和观察题仍完整。

## 6. `PERF-001-REAL-LOW-END`：低端真机与降级

| 字段 | 内容 |
| --- | --- |
| 级别 | P1 |
| 当前状态 | **待人工执行；当前不得宣称“低端手机流畅运行”** |
| 设备选择 | 发布前由项目负责人固定具体型号、内存和选择理由；“低端机”不能只作为无型号的形容词 |
| 重复 | 冷缓存 3 次，热缓存 3 次 |
| 证据 | 原始浏览器跟踪、HAR/请求清单、帧时间数据、连续录屏和汇总表 |

每次固定步骤：

1. 记录打开页面到 2D 内容可读的时间和 2D 首屏传输字节。
2. 主动启动 3D，记录到首个可交互帧的时间、3D 新增传输字节、draw calls 和 triangles。
3. 预热 3 秒，然后持续单指拖动 10 秒，保存逐帧时间。
4. 如任一连续 5 秒低于 30 FPS，确认 DPR 降到 `0.75` 并重复同一脚本；仍不达标时必须回到 2D，且本次会话不自动恢复 3D。
5. 汇总六次运行的中位数和最差值，不删除失败轮次。

达到 README 的传输、几何和降级预算后才能标记通过。只有桌面模拟、开发者电脑或一次肉眼观察时，状态仍为“未执行”。

## 8. `BUILD-001`：独立复现顺序

未参与实现的第二位开发者必须在全新 clone 中执行：

```bash
git checkout --detach <release-commit>
test -z "$(git status --porcelain)"
nvm use
test "$(node --version)" = "v24.13.0"
test "$(npm --version)" = "11.6.2"
npm ci
npm run repro:check
npm run test:data
npm run typecheck
npm run lint
npm run build
npm run test:e2e
```

每条命令保存原始标准输出、标准错误、开始时间、结束时间和退出码。只有所有 P0/P1 技术用例通过，且真机待办已有明确结论时，才能完成 G7a。
