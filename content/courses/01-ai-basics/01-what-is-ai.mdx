<section id="what-is-ai" className="lesson-section">
  <p className="lesson-section-number">02 · 建立概念</p>
  <h2>人工智能是什么</h2>
  <p>人工智能不是某一种机器人，也不只是聊天工具。用适合本课的方式来说：</p>

  <Callout title="人工智能系统会根据接收到的信息，利用模型进行推断，再产生预测、内容、建议或决定等结果。">
    <p>这些结果可能影响屏幕里的虚拟世界，也可能控制现实中的设备。不同系统的自主程度不同，有些还会在使用中适应新的情况。</p>
  </Callout>

  <p>这里最值得注意的词是<strong>“推断”</strong>。系统不是简单查找一条固定答案，而是根据模型中学到的模式，判断什么结果更可能合适。例如，一张从未见过的猫的照片，图像识别系统仍可能根据耳朵、轮廓和纹理等模式判断“这可能是一只猫”。</p>

  <Callout tone="idea" label="容易混淆" title="“看起来聪明”不等于“像人一样理解”">
    <p>人工智能可以在特定任务中表现得很出色，但这并不说明它拥有人的生活经验、情感或完整理解。描述它时，说“系统识别、预测或生成”通常比说“它懂了”更准确。</p>
  </Callout>
</section>

<section id="ai-or-automation" className="lesson-section">
  <p className="lesson-section-number">03 · 学会辨别</p>
  <h2>人工智能、自动化与普通程序</h2>
  <p className="section-intro">它们都能帮助人完成任务，也常常组合在同一个产品里。判断时不要只看“新不新”或“酷不酷”，要看它怎样得到结果。</p>

  <ComparisonCards items={[
    { name: '普通程序', cue: '照明确规则计算', method: '开发者写好清楚、确定的步骤，输入相同通常得到相同结果。', example: '计算器计算乘法、按规则检查密码长度。' },
    { name: '自动化', cue: '满足条件就行动', method: '当时间、温度或传感器等条件达到设定值，系统自动执行动作。', example: '定时浇水、感应灯亮起、固定程序煮饭。' },
    { name: '人工智能', cue: '根据模式作推断', method: '模型根据输入中的模式，给出预测、分类、内容或建议，结果可能不确定。', example: '语音识别、图片分类、内容推荐。' },
  ]} />

  <p>现实产品的边界并不总是整齐。例如，智能空调可能先用普通程序读取温度，再用人工智能预测使用习惯，最后通过自动化规则调节风速。因此，更好的问题是：<strong>这个功能的哪一步使用了人工智能？</strong></p>
</section>

<section id="how-ai-works" className="lesson-section">
  <p className="lesson-section-number">04 · 看懂过程</p>
  <h2>人工智能怎样完成任务</h2>
  <p className="section-intro">我们可以先用四个环节理解一次人工智能任务。以“判断照片里是否有猫”为例：</p>

  <ProcessFlow steps={[
    { label: '输入', title: '接收信息', description: '系统接收一张照片。声音、文字、位置或传感器数据也可以成为输入。' },
    { label: '模型', title: '寻找学到的模式', description: '模型把照片中的特征与训练时学到的模式进行比较。' },
    { label: '输出', title: '给出推断结果', description: '系统输出“像猫”的概率或分类，但结果不保证正确。' },
    { label: '核验', title: '由人检查与使用', description: '人结合场景判断结果是否可信，并决定下一步行动。' },
  ]} />

  <h3>模型从哪里学到模式？</h3>
  <p>在使用之前，开发者会用许多示例训练模型。训练过程不断比较模型的结果和期望结果，再调整内部参数，让错误逐渐减少。训练完成后，模型才被用来处理新的输入。<strong>训练</strong>像是通过大量练习形成能力，<strong>使用</strong>则是拿这项能力解决眼前任务。</p>

  <Callout tone="caution" label="请记住" title="数据会影响模型学到什么">
    <p>如果训练数据不完整、包含错误，或者没有代表不同人群和场景，模型的结果也可能不准确或不公平。数据多并不自动等于数据好。</p>
  </Callout>
</section>

<section id="limits-and-safety" className="lesson-section">
  <p className="lesson-section-number">06 · 负责任地使用</p>
  <h2>能力、限制与安全</h2>
  <p>人工智能擅长识别模式、处理大量信息、生成内容和提供建议。它可以成为学习伙伴，但不能替我们承担判断和责任。</p>

  <div className="safety-grid">
    <article>
      <span>01</span>
      <h3>结果可能出错</h3>
      <p>重要事实至少用可靠来源再次核对；遇到医疗、安全等问题，应请可信赖的成年人或专业人士帮助。</p>
    </article>
    <article>
      <span>02</span>
      <h3>保护个人信息</h3>
      <p>不要随意输入真实姓名、住址、联系方式、账号密码，以及包含他人隐私的照片和文件。</p>
    </article>
    <article>
      <span>03</span>
      <h3>人要保持判断</h3>
      <p>先想清楚自己的目标，再使用工具；说明人工智能提供了哪些帮助，并对最终作品负责。</p>
    </article>
    <article>
      <span>04</span>
      <h3>留意公平影响</h3>
      <p>当结果影响他人时，问一问：数据是否完整？规则是否公平？有没有人被忽略或受到伤害？</p>
    </article>
  </div>

  <ReflectionPrompt title="家庭讨论：把“为什么”说出来">
    <p>请学生挑选一个经常使用的智能功能，向家长解释它的输入、输出、可能的错误和安全使用方法。家长先追问理由，不急着判断对错。</p>
  </ReflectionPrompt>
</section>
